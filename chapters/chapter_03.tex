\chapter{Lawvere's fixed-point theorem}
We have developed the necessary tools to prove Lawvere's fixed-point theorem; therefore, we can now state and prove it.
We will see two versions of this theorem, one for cartesian closed categories, and one for cartesian categories.
Moreover, we will show, in both cases, all the main applications and examples of the theorems, focusing on how diagonal arguments and fixed-point theorems
can be retrieved as instances of Lawvere's theorem, choosing the appropriate category to work in.

\section{Surjections and fixed points in categories}
Let's start by recalling some useful notions in category theory that are necessary to state Lawvere's theorem.

\begin{definition}[Global element]
    Let $\mathcal C$ be a category with terminal object $1$. Given an object $A$ of $\mathcal C$, a \emph{global element} of $A$,
    or just \emph{element} of $A$, is a morphism $1 \to A$.
\end{definition}

\begin{definition}[Endomorphism]
    Let $\mathcal C$ be a category and $A$ an object of $\mathcal C$. An \emph{endomorphism} of $A$ is a morphism $f: A \to A$.
\end{definition}

\begin{definition}[Fixed point]
    In a category $\mathcal C$ with terminal object $1$, given an endomorphism $f: A \to A$, we say that $f$ has a \emph{fixed point} if there
    exists a global element $x: 1 \to A$ such that $f \circ x = x$.
\end{definition}

\begin{definition}[Surjection]
    In a category $\mathcal C$, given a morphism $f: A \to B$, we say that $f$ is a \emph{surjection} if there exists a morphism $s : B \to A$ such that $f \circ s = 1_B$.
\end{definition}

\begin{remark}
    Often the surjections defined above are called \emph{split epimorphisms}, and the morphism $s$ is called a \emph{section} of $f$.
\end{remark}

\begin{definition}[Point-surjective morphism]
    In a category $\mathcal C$ with terminal object $1$, given a morphism $f: A \to B$, we say that $f$ is \emph{point-surjective} if for every
    element $b: 1 \to B$ there exists an element $a: 1 \to A$ such that $f \circ a = b$.
\end{definition}

\begin{remark}[Surjective implies point-surjective]
    Obviously, in a category with terminal object, every surjection is point-surjective. This is trivial, since, given $f: A \to B$ a surjection and $b: 1 \to B$, we have
    \[ f \circ s = 1_B \implies f \circ (s \circ b) = 1_B \circ b = b; \]
    therefore, we can take $s \circ b : 1 \to A$ as an element realizing $b$.
\end{remark}

The following definition will be very useful for the examples in the next sections. However, we introduce it now for the upcoming example.

\begin{definition}[Concrete category]
    A category $\mathcal C$ is \emph{concrete} if there exists a \emph{faithful} functor $U : \mathcal C \to \mathsf{Set}$, called a \emph{forgetful functor}.
    To be faithful means that, given $f,g \in \Hom_{\mathcal C}(A,B)$, if $U(f) = U(g)$, then $f = g$, i.e.,\ if the underlying set-theoretic functions of two morphisms are equal, then the morphisms themselves are equal.
\end{definition}

Being a concrete category basically means that the objects of the category can be seen as sets, and the morphisms as set-theoretic functions, possibly with some extra structure.
In addition, the function structure determines the morphism structure.

\begin{example}[Point-surjective morphism that is not surjective]
    In the category $\mathsf{Grp}$, consider the unique homomorphism $i : 1 \to \ZZ$, where $1 = \{e\}$ and $i(e) = 0$. This map is point-surjective, since
    the only possible homomorphism $1 \to \ZZ$ is the trivial one; therefore, the only global element of $\ZZ$ is $0$, and $i$ realizes it by taking $1_1$.
    However, this map is not surjective, since if there was $s : \ZZ \to 1$ such that $i \circ s = 1_\ZZ$, then $U(i) \circ U(s) = 1_{U(\ZZ)}$, where $U : \mathsf{Grp} \to \mathsf{Set}$ is the forgetful functor.
    Therefore $U(i) : U(1) \to U(\ZZ)$ would be surjective, but this is impossible since $|U(1)| = 1 < |U(\ZZ)| = \aleph_0$.
\end{example}

\begin{definition}[Weakly point-surjective morphism]
    In a category $\mathcal C$ with terminal object $1$, given a morphism $f : A \to C^B$, if there exists the evaluation morphism $\ev_{C,B}$,
    we say that $f$ is \emph{weakly point-surjective} if for every element $g: 1 \to C^B$ there exists an element $a_g : 1 \to A$ such that, for every $b: 1 \to B$, we have
    \[ (f \circ a_g)^\sharp \circ b = g^\sharp \circ b. \]
\end{definition}

\begin{notation}
    We use the notation $(-)^\sharp$ to denote the evaluation morphism, i.e.,\ if $h : 1 \to C^B$, then $h^\sharp := \ev_{C,B} \circ \langle h \circ !_B, 1_B \rangle : B \to C$.
    This way $h^\sharp \circ b = \ev_{C,B} \circ \langle h,b \rangle$ for every $b: 1 \to B$.
\end{notation}

\begin{remark}[Point-surjective implies weakly point-surjective]
    Let $\mathcal C$ be a category with terminal object $1$; given $f : A \to C^B$, if $f$ is point-surjective, then it is also weakly point-surjective.
    Indeed, given $g: 1 \to C^B$, since $f$ is point-surjective, there exists an element $a_g : 1 \to A$ such that $f \circ a_g = g$; therefore,
    applying $(-)^\sharp$ and precomposing with any $b$, we have the pointwise equality $(f \circ a_g)^\sharp \circ b = g^\sharp \circ b$.
\end{remark}

\begin{example}[Weakly point-surjective but not point-surjective morphism]
    Consider the cartesian closed category $\mathsf{InvSet}$ of sets with an involution and \emph{equivariant} maps, where a function $f : (X,s_X) \to (Y,s_Y)$ is equivariant if $f \circ s_X = s_Y \circ f$. Let $B = \{0,1\}$ with the involution $s$ that exchanges $0$ and $1$, and let $i : 1 \to B^B$ be the global element corresponding to $1_B : B \to B$.
    The map $i$ is weakly point-surjective, since $B$ has no global elements, so the condition in the definition is vacuously satisfied.
    However, $s : B \to B$ is equivariant and determines a global element $k : 1 \to B^B$ distinct from $i$. Since $1_1$ is the only global element of $1$, there is no $a : 1 \to 1$ such that $i \circ a = k$, so $i$ is not point-surjective.
\end{example}

\begin{definition}[Diagonal morphism]
    In a category $\mathcal C$, given an object $A$, we call $\Delta_A : A \to A \times A$ the \emph{diagonal morphism} of $A$,
    defined as $\Delta_A := \langle 1_A, 1_A \rangle$.
\end{definition}

\section{The fixed-point theorem}

\begin{theorem}[Lawvere's fixed-point]
    Let $\mathcal C$ be a cartesian closed category; if there exists a weakly point-surjective morphism $\phi : A \to B^A$, then every endomorphism $f: B \to B$ has a fixed point.
\end{theorem}

\begin{proof}
    Let $f : B \to B$ be an endomorphism.
    By the equivalence $\mathsf{CCC} \simeq \lambda\text{-}\mathsf{Calc}$, Theorem~\ref{thm:curry-howard-lambek-without-wnno-and-iterator}, we apply $\mathbf L : \mathsf{CCC} \to \lambda\text{-}\mathsf{Calc}$ to $\mathcal C$ and work in its internal language $\mathbf L(\mathcal C)$.
    By the definition of $\mathbf L$, the objects of $\mathcal C$ become types and its global elements become closed terms; composition becomes substitution, while evaluation and currying become application and abstraction.
    Using the fact that $\ulcorner f \urcorner : 1 \to B^B$ and $\ulcorner \phi \urcorner : 1 \to (B^A)^A$, and taking the respective closed terms in $\mathbf L(\mathcal C)$, we define the following closed term
    \[ q := \lambda_{x \in A} \ulcorner f \urcorner^\sharp \mathopen{\scalebox{1}[1.35]{$($}}\underbrace{\mathopen{\scalebox{1}[1.15]{$($}}\underbrace{\ulcorner \phi \urcorner^\sharp(x)}_{\makebox[0pt][c]{$\scriptstyle\text{function coded by }x$}}\mathclose{\scalebox{1}[1.15]{$)$}}^\sharp(x)}_{\text{applied to its own code}}\mathclose{\scalebox{1}[1.35]{$)$}} \in B^A. \]
    This closed term in $\mathbf L(\mathcal C)$ corresponds to the global element
    \[ q = \ulcorner f \circ \ev_{B,A} \circ (\phi \times 1_A) \circ \Delta_A \urcorner : 1 \to B^A, \]
    in $\mathcal C$. The weak point-surjectivity of $\phi$, expressed in $\mathbf L(\mathcal C)$, gives a closed term $p \in A$, equivalently an element $p : 1 \to A$, that can be regarded as a pointwise code of $q$, such that
    \[ \left(\ulcorner \phi \urcorner^\sharp(p)\right)^\sharp(a) \underset{\varnothing}{=} q^\sharp(a), \]
    for every closed term $a \in A$. Taking $a=p$, we define the closed term, $q$ applied to its own code
    \[ s := \left(\ulcorner \phi \urcorner^\sharp(p)\right)^\sharp(p) \underset{\varnothing}{=} q^\sharp(p) \in B. \]
    At the same time, using the above definition of $q$, we have
    \begin{align*}
        q^\sharp(p) &\underset{\varnothing}{=} (\lambda_{x \in A}\ulcorner f \urcorner^\sharp ((\ulcorner \phi \urcorner^\sharp(x))^\sharp(x)))^\sharp(p) \\
                    &\underset{\varnothing}{=} \ulcorner f \urcorner^\sharp((\ulcorner \phi \urcorner^\sharp(p))^\sharp(p)) &&(\text{$\beta$-reduction}) \\
                    &\underset{\varnothing}{=} \ulcorner f \urcorner^\sharp(s).
    \end{align*}
    Thus $\ulcorner f \urcorner^\sharp(s) \underset{\varnothing}{=} s$ in $\mathbf L(\mathcal C)$. We now apply $\mathbf C : \lambda\text{-}\mathsf{Calc} \to \mathsf{CCC}$ to $\mathbf L(\mathcal C)$. By the definition of $\mathbf C$, closed terms determine arrows as equivalence classes of pairs; equality of terms gives equality of the corresponding classes, and composition is defined by substitution.
    Therefore, if $u \in 1$ is a variable, we find the following arrow equation in $\mathbf C(\mathbf L(\mathcal C))$:
    \[ [(x \in B,\ulcorner f \urcorner^\sharp(x))] \circ [(u \in 1,s)] = [(u \in 1,s)] \quad\text{in } \mathbf C(\mathbf L(\mathcal C)). \]
    Finally, the equivalence of categories $\mathsf{CCC} \simeq \lambda\text{-}\mathsf{Calc}$ provides us the natural isomorphism $\varepsilon : \mathbf C \circ \mathbf L \overset{\cong}{\Rightarrow }1_{\mathsf{CCC}}$,
    whose component at $\mathcal C$ is the isomorphism
    \[ \varepsilon_{\mathcal C} : \mathbf C(\mathbf L(\mathcal C)) \xrightarrow{\cong} \mathcal C. \]
    By the definition of $\varepsilon_{\mathcal C}$ given in the proof of \Cref{thm:curry-howard-lambek-without-wnno-and-iterator}, we have
    \[ \varepsilon_{\mathcal C}([(x \in B,\ulcorner f \urcorner^\sharp(x))]) = f, \qquad \varepsilon_{\mathcal C}([(u \in 1,s)]) = s, \]
    because $\ulcorner f \urcorner^\sharp(x) \underset{x}{=} \ev_{B,B} \circ \langle \ulcorner f \urcorner, x \rangle \underset{x}{=} \ev_{B,B} \circ \langle \ulcorner f \urcorner \circ !_B, 1_B \rangle \circ x \underset{x}{=} f \circ x$, using the definition of $(-)^\sharp$
    and the fact that $\mathcal C[x]$ is a CCC, so $\ulcorner f \urcorner^\sharp = f$; and $s \circ u \underset{u}{=} s \circ 1_1 = s$ in $\mathcal C[u]$, since $s$ is a closed term.
    Therefore, the functoriality of $\varepsilon_{\mathcal C}$ transports the preceding arrow equation to $f \circ s=s$ in $\mathcal C$, so $s$ is a fixed point of $f$.
\end{proof}

\section{Many fixed-points, one proof}\label{sec:many-fixed-points-one-proof}
Let's now see how Lawvere's fixed-point theorem can be used to prove many other fixed-point theorems, diagonal arguments and even other useful results in logic and mathematics in general.
For each result, we will introduce the category needed to apply Lawvere's theorem, and we will show how the hypotheses of the theorem are satisfied in that category.

Before we start, we recall a couple of useful notions in computability theory, which will be used multiple times in the following sections.

\begin{notation}[Recursive functions]\label{idx:partial-naturals}
    We denote by $\NN_\bot := \NN \cup \{\bot\}$ the set of natural numbers with a bottom element $\bot$,
    which denotes the non-termination of a computation. We assume the notions of \emph{partial recursive function} (or just \emph{recursive function}),
    \emph{total recursive function} and \emph{primitive recursive function}; we won't define them here, but we refer the reader to \Cite[Definition~2.1, pp.~5--6]{Streicher2002} for the detailed definitions.
\end{notation}

\begin{definition}[Decidable and semidecidable sets]
    We say that a subset $A \subseteq \NN^k$ is \emph{decidable} if there exists a total recursive function $f : \NN^k \to \NN$ such that
    \[ A = \{\vec x \in \NN^k : f(\vec x) = 0\}. \]
    Similarly, we say that a subset $A \subseteq \NN^k$ is \emph{semidecidable} if there exists a partial recursive function $f : \NN^k \to \NN_\bot$ such that
    \[ A = \{\vec x \in \NN^k : f(\vec x) \ne \bot\}. \]
\end{definition}

We assume the following result.

\begin{proposition}[{\cite[Definition~5.1 and Lemma~5.1, pp.~17--18]{Streicher2002}}]
    Given a subset $A \subseteq \NN^k$, TFAE:
    \begin{itemize}
        \item $A$ is semidecidable;
        \item $A$ is \emph{recursively enumerable} (r.e.), i.e., either $A = \varnothing$ or there exists a total recursive function $f : \NN \to \NN^k$ such that $A = \Img(f)$;
        \item $A$ is the domain of a partial recursive function, i.e.
        \[ A = \{\vec x \in \NN^k : f(\vec x) \ne \bot\}, \]
        for some partial recursive function $f : \NN^k \to \NN_\bot$.
    \end{itemize}
\end{proposition}

\begin{notation}[Universal partial recursive function]\label{idx:universal-function}
    We denote by $u_k : \NN^{k+1} \to \NN_\bot$ the universal partial recursive function for $k$-ary partial recursive functions, see \Cite[Definition~4.1, p.~13]{Streicher2002} for the definition.
\end{notation}

\subsection*{Cantor's theorem}
In $\mathsf{Set}$ we can prove Cantor's theorem, on the non-existence of surjections from a set to its power set.

\begin{theorem}[Cantor's theorem]
    Let $A$ be a set; then there is no surjection $f: A \twoheadrightarrow \mathcal P(A)$.
\end{theorem}

\begin{proof}
    Take $A \in \ob(\mathsf{Set})$; given the bijection $|2^A| = |\mathcal P(A)|$, we can equivalently prove that there is no surjection $f: A \twoheadrightarrow 2^A$.
    Let's assume, by contradiction, that there exists a surjection $f: A \twoheadrightarrow 2^A$. Since $\mathsf{Set}$ is cartesian closed,
    and surjections are weak point-surjective maps, by Lawvere's fixed-point theorem, every endomorphism $g : 2 \to 2$ has a fixed point.
    That is a contradiction, since the endomorphism $\neg : 2 \to 2$, defined as $\neg(0) = 1$ and $\neg(1) = 0$, has no fixed points.
\end{proof}

\subsection*{Cantor's diagonal argument}
By Cantor's diagonal argument, we mean the fact that $|\NN| < |\RR|$, proved through Cantor's diagonalization.
Even though this result can be obtained as a corollary of Cantor's theorem, we can also prove it directly using Lawvere's fixed-point theorem.

\begin{theorem}[Cantor's diagonal argument]
    $|\NN| < |\RR|$.
\end{theorem}

\begin{proof}
    Let's consider the inclusion $\iota : 2^\NN \hookrightarrow \RR$, defined as
    \[ \iota : (a_i)_{i \in \NN} \mapsto \sum_{i \in \NN} a_i 10^{-(i+1)}. \]
    This is indeed injective, since if $(a_i)_{i \in \NN} \ne (b_i)_{i \in \NN}$, then there exists a minimum $i_0 \in \NN$ such that, WLOG, $a_{i_0} = 1$ and $b_{i_0} = 0$; therefore,
    it is easy to see that $\iota((a_i)_{i \in \NN}) - \iota((b_i)_{i \in \NN}) \geq \frac 89 10^{-(i_0+1)} > 0$.\newline
    Let $s : \RR \to 2^\NN$ be a left-inverse of $\iota$, defined as
    \[ s : \RR \twoheadrightarrow 2^\NN : x \mapsto \begin{cases}
        \iota^{-1}(x) & \text{if $x \in \Img(\iota)$} \\
        (0)_{i \in \NN} & \text{otherwise}
    \end{cases}. \]
    Given an arbitrary map $f : \NN \to \RR$, define $\phi:=s \circ f : \NN \to 2^\NN$.
    We specialize the construction in the proof of Lawvere's fixed-point theorem to $\mathcal C=\mathsf{Set}$, $A=\NN$, $B=2$, the map $\phi$, and the endomorphism $\neg : 2 \to 2$.
    We construct the term
    \[ d := \lambda_{i \in \NN}\ulcorner \neg \urcorner^\sharp((\ulcorner \phi \urcorner^\sharp(i))^\sharp(i)) \in 2^\NN, \]
    and, under the identification of the elements of $2^\NN$ with binary sequences, we have, by $\beta$-reduction, that
    \[ d^\sharp(i) \underset{\{i\}}{=} \ulcorner \neg \urcorner^\sharp((\ulcorner s \urcorner^\sharp(\ulcorner f \urcorner^\sharp(i)))^\sharp(i)). \]
    Thus $d$ is precisely the diagonal sequence: its $i$-th coordinate is the negation of the $i$-th coordinate of the $i$-th sequence $\ulcorner \phi \urcorner^\sharp(i)$.\newline
    If $d \in \Img(\phi)$, there would exist $p \in \NN$ such that $\ulcorner \phi \urcorner^\sharp(p) \underset{\varnothing}{=}d$.
    The calculation obtained by taking $a=p$ in the proof of Lawvere's theorem would then give
    \[ 2 \ni b := (\ulcorner \phi \urcorner^\sharp(p))^\sharp(p) \underset{\varnothing}{=} d^\sharp(p) \underset{\varnothing}{=} \ulcorner \neg \urcorner^\sharp((\ulcorner \phi \urcorner^\sharp(p))^\sharp(p)) \underset{\varnothing}{=} \ulcorner \neg \urcorner^\sharp(b), \]
    contradicting the fact that negation has no fixed point in $2$. Hence, $d \notin \Img(\phi)$.
    Finally, let $x_d:=\ulcorner \iota \urcorner^\sharp(d) \in \RR$ and let's check that $x_d \notin \Img(f)$. If $x_d \underset{\varnothing}{=}\ulcorner f \urcorner^\sharp(k)$ for some $k \in \NN$, then
    \[ \ulcorner \phi \urcorner^\sharp(k) \underset{\varnothing}{=}\ulcorner s \urcorner^\sharp(\ulcorner f \urcorner^\sharp(k)) \underset{\varnothing}{=}\ulcorner s \urcorner^\sharp(x_d) \underset{\varnothing}{=}\ulcorner s \urcorner^\sharp(\ulcorner \iota \urcorner^\sharp(d)) \underset{\varnothing}{=}d, \]
    where the last equality holds since, in $\mathsf{Set}$, $s \circ \iota = 1_{2^\NN}$, so we have a contradiction.
    Therefore $x_d \notin \Img(f)$, and, since $f : \NN \to \RR$ was arbitrary, there is no surjection $\NN \twoheadrightarrow \RR$, because we constructed the diagonal element $x_d \in \RR$.
\end{proof}

\subsection*{Russell's paradox}
Another instance of Lawvere's argument in $\mathsf{Set}$ is Russell's paradox, which can be, informally, stated as the class of all sets is not a set.
Let's give some preliminary definitions to formalize this statement.

\begin{definition}[Axiom schema of separation]
    Let $A$ be a set and let $\varphi(x)$ be a formula in the language of set theory. The \emph{axiom schema of separation} states that
    \[ B = \{ x \in A : \varphi(x) \} \]
    is a set.
\end{definition}

\begin{definition}[Class of all sets]
    We call $V$ the \emph{class of all sets} defined by the formula $x = x$, i.e.
    \[ V := \{ x : x = x \}. \]
\end{definition}

\begin{theorem}[Russell's paradox]
    Axiom schema of separation $\implies \neg(V \in \mathsf{Set})$.
\end{theorem}

\begin{proof}
    Let's assume, by contradiction, that $V \in \mathsf{Set}$, so $2^V \in \mathsf{Set}$, by the power set axiom.
    We define the map
    \[ \phi : V \to 2^V : a \mapsto \mathbf 1_a(x) = \begin{cases}
        1 & \text{if $x \in a$} \\
        0 & \text{if $x \notin a$}
    \end{cases},\]
    that sends each set to its indicator function. This map is surjective, since, given $f : V \to 2$, we can define the set $a_f := \{ x \in V : f(x) = 1 \}$, by the axiom schema of separation.
    Therefore, by Lawvere's fixed-point theorem, every endomorphism $2 \to 2$ has a fixed point, which is a contradiction.
\end{proof}

\begin{remark}[On the axioms used in the proof of Russell's paradox]
    Technically, in the previous proof, we used the axioms of \emph{extensionality}, \emph{pairing}, \emph{union}, \emph{power set}, and \emph{separation}.
    Working by contradiction, all the other axioms follow from $V \in \mathsf{Set}$ + separation, so the statement of the theorem is technically accurate.
\end{remark}

\subsection*{Non-existence of certain continuous surjections}
Another interesting application of Lawvere's fixed-point theorem is the non-existence of certain continuous surjections, in $k\mathsf{Top}$, the category of compactly generated Hausdorff spaces.

\begin{definition}[Compactly generated space]
    A topological space $X$ is \emph{compactly generated} if a subset $A \subseteq X$ is open if and only if $A \cap K$ is open in $K$ for every compact subspace $K \subseteq X$.
\end{definition}

\begin{remark}
    We recall the following chain of implications, useful to check if a space is compactly generated:
    \[ \textrm{metrizable} \implies \textrm{first-countable} \implies \textrm{Fréchet--Urysohn}\implies \textrm{sequential} \implies k\mathsf{Top}. \]
    There's also another useful chain:
    \[ \textrm{compact} \implies \textrm{locally compact} \implies \textrm{compactly generated}. \]
\end{remark}

\begin{notation}
    From now until the end of this subsection, we will denote by $k\mathsf{Top}$ the category of compactly generated Hausdorff spaces, whose objects are compactly generated Hausdorff spaces and whose morphisms are continuous maps.\label{idx:compactly-generated}
\end{notation}

\begin{remark}
    Checking that $k\mathsf{Top}$ is cartesian closed is neither trivial nor too difficult, but it requires some work. Therefore, we will assume it without proving it, and we refer to \Cite{Rezk2018} for a complete proof.
\end{remark}

Let's now see some of these results.

\begin{proposition}
    Given $I, X$ compactly generated Hausdorff spaces, if there is a continuous endomorphism $f : X \to X$ without fixed points, then there is no continuous surjection
    \[ g : I \twoheadrightarrow X^I. \]
\end{proposition}

\begin{proof}
    It is just the contrapositive of Lawvere's fixed-point theorem, applied to $k\mathsf{Top}$.
\end{proof}

\begin{example}
    For example, there is no continuous surjection $g : [0,1] \to (S^1)^{[0,1]} = C^0([0,1],S^1)$, since the continuous endomorphism $f : S^1 \to S^1$ defined as $f(v) = -v$, the \emph{antipodal map}, has no fixed points.
\end{example}

More generally, we can prove the following result.

\begin{proposition}
    Given $G$ a compactly generated Hausdorff group and $I$ a compactly generated Hausdorff space, if $G$ is nontrivial, then there is no continuous surjection
    \[ g : I \twoheadrightarrow G^I. \]
\end{proposition}

\begin{proof}
    Given a nontrivial element $g \in G$ we can define the translation map
    \[ L_g : G \to G : x \mapsto g \cdot x, \]
    which is continuous, since $G$ is a topological group, and has no fixed points; otherwise, $g \cdot x = x \implies g = 1_G$, contradicting the fact that $g$ is nontrivial.
    Now we can apply the previous proposition to conclude.
\end{proof}

Other interesting examples include the following.

\begin{example}
    Given $(0,1) \subseteq \RR$, $f(x) := \frac{x + 1}{2}$ has no fixed points, so there is no continuous surjection $g : I \twoheadrightarrow (0,1)^I$, for any compactly generated Hausdorff space $I$.
\end{example}

\begin{example}
    If $X$ has a continuous endomorphism $f : X \to X$ without fixed points, then for every compactly generated Hausdorff space $Y$, the map
    \[ f \times 1_Y : X \times Y \to X \times Y : (x,y) \mapsto (f(x),y) \]
    is a continuous endomorphism without fixed points, so there is no continuous surjection $g : I \twoheadrightarrow (X \times Y)^I$.
    In particular, there is no continuous surjection $g : I \twoheadrightarrow (S^n \times Y)^I$, for $I, Y \in \ob(k\mathsf{Top})$ and $n \geq 1$.
\end{example}

\begin{example}
    Given $X$ a compactly generated Hausdorff space, then the map
    \[ f : X \sqcup X \to X \sqcup X : (x,0) \mapsto (x,1), (x,1) \mapsto (x,0) \]
    is a continuous endomorphism without fixed points, so there is no continuous surjection $g : I \twoheadrightarrow (X \sqcup X)^I$.
\end{example}

\begin{example}
    The Cantor space $2^\NN$, equipped with the product topology, is a compactly generated Hausdorff space, and the map
    \[ f(x_0,x_1,x_2,\dots) := (1-x_0,x_1,x_2,\dots) \]
    is a continuous endomorphism without fixed points: if there was one, we'd have $x_0 = \frac 12 \not\in 2$, so there is no continuous surjection $g : I \twoheadrightarrow (2^\NN)^I$, for any compactly generated Hausdorff space $I$.
\end{example}

\subsection*{Rice's theorem}
Let's now see how to apply Lawvere's fixed-point theorem to obtain some result in computability theory. Specifically, we prove in this subsection Rice's theorem.

\begin{theorem}[Rice's theorem]
    Let $R \subseteq \NN$ be such that for all $\alpha,\beta \in\NN$
    \[ \left(\forall x \in \NN \; u_1(\alpha,x) = u_1(\beta,x)\right) \implies (\alpha \in R \iff \beta \in R),\]
    i.e.,\ $R$ is an \emph{extensional property} of the partial recursive functions. If $R$ is decidable, either $R = \varnothing$ or $R = \NN$.
\end{theorem}

What the theorem says is that, if $R$ is a nontrivial extensional property of the partial recursive functions, then $R$ is undecidable.

\begin{remark}
    Rice's theorem generalizes Turing's halting problem, i.e. the set $H_1 := \{(\alpha,x) \in \NN^2 | u_1(\alpha,x) \ne \bot\}$ is undecidable.
    Indeed, if $H_1$ was decidable, we'd have
    \[ H_1 = \{(\alpha,x) \in \NN^2 | f(\alpha,x) = 0\}, \]
    for some $f : \NN^2 \to 2$ total recursive function. Therefore, the sections of $H_1$ would be decidable too, i.e.\ for a fixed $x \in \NN$, the set $H_1^x := \{\alpha \in \NN | (\alpha,x) \in H_1\}$ would be decidable,
    since $\alpha \in H_1^x \iff f(\alpha,x) = 0$. Now $H_1^x$ is an extensional property of the partial recursive functions, because if $\alpha,\beta \in \NN$ are such that $u_1(\alpha,y) = u_1(\beta,y)$ for every $y \in \NN$,
    then in particular $u_1(\alpha,x) = u_1(\beta,x)$, so $\alpha \in H_1^x \iff \beta \in H_1^x$. Therefore, by Rice's theorem, $H_1^x$ is either empty or the whole $\NN$; that is a contradiction, since there are programs that halt on input $x$ - we can define one specifically to do this - and programs that do not halt on input $x$ - for example one that loops forever on every input.
\end{remark}

In order to prove Rice's theorem, we introduce the category $\mathsf{Asm}(\mathcal K_1)$ of \emph{assemblies} over the first Kleene algebra $\mathcal K_1 = (\NN,\cdot)$, where $e \cdot n := u_1(e,n)$.\label{idx:kleene-algebra}

\begin{definition}[$\mathsf{Asm}(\mathcal K_1)$]\label{idx:assemblies}
    The category $\mathsf{Asm}(\mathcal K_1)$ is called the category of \emph{assemblies} over the first Kleene algebra $\mathcal K_1$, and it is defined as follows:
    \begin{itemize}
        \item the objects are pairs $X = (|X|,\Vdash_X)$, called \emph{assemblies}, where $|X|$ is a set and $\Vdash_X \subseteq \NN \times |X|$ is a relation, called the \emph{realizability relation}, such that for every $x \in |X|$ there exists $n \in \NN$ for which $n \Vdash_X x$ - we say that $n$ \emph{realizes} $x$;\label{idx:realizability}
        \item a morphism of assemblies $f : X \to Y$ is a set-theoretic function $f : |X| \to |Y|$ such that there exists $e \in \NN$, called a \emph{tracker} of $f$, for which
        \[ n \Vdash_X x \implies e \cdot n \ne \bot \text{ and } e \cdot n \Vdash_Y f(x), \]
        for every $x \in |X|$ and $n \in \NN$.
    \end{itemize}
\end{definition}

\begin{remark}
    We can have two trackers $e_1,e_2 \in \NN$ for the same morphism $f : X \to Y$; therefore, it's important to point out that the morphisms are the functions $f$ with the property of having at least one tracker, and not the pairs $(f,e)$.
\end{remark}

\begin{proposition}
    $\mathsf{Asm}(\mathcal K_1)$ is a cartesian closed category.
\end{proposition}

\begin{proof}
    Let's first check that $\mathsf{Asm}(\mathcal K_1)$ is a category.
    \begin{itemize}
        \item The identity map $1_X : |X| \to |X|$ is a morphism of assemblies, since, if $n \Vdash_X x$, then, taking $e := \ulcorner 1\cdot\urcorner \in \NN$, we have that $e \cdot n = n \ne \bot$ and $e \cdot n \Vdash_X 1_X(x) = x$.
        \item Given $f : X \to Y$ and $g : Y \to Z$ morphisms of assemblies, we fix two trackers $e_f$ and $e_g$ of $f$ and $g$. Now, given $n \Vdash_X x$, we have $e_f \cdot n \Vdash_Y f(x)$, and from this
        \[ e_g \cdot (e_f \cdot n) \Vdash_Z (g \circ f)(x). \]
        By taking $e := \ulcorner u_1(e_g,u_1(e_f,-)) \urcorner \in \NN$, we have that $e \cdot n \Vdash_Z (g \circ f)(x)$.
        Moreover, since $e_f \cdot n \ne \bot$ and $e_g \cdot (e_f \cdot n) \ne \bot$, we have $e \cdot n \ne \bot$, so $e$ is a tracker of $g \circ f$, and therefore $g \circ f : X \to Z$ is a morphism of assemblies.
    \end{itemize}
    To prove that $\mathsf{Asm}(\mathcal K_1)$ is cartesian closed, we need to prove the existence of a terminal object, the existence of binary products, and the existence of exponentials.
    \begin{itemize}
        \item The terminal object is $1 := (\{*\},\Vdash_1)$, where $n \Vdash_1 *$ for every $n \in \NN$. Indeed, given a morphism $f : X \to 1$,
        since $\mathsf{Asm}(\mathcal K_1)$ is a concrete category, the underlying function $|f| : |X| \to \{*\}$ is uniquely determined; moreover,
        given any $e \in \NN$ such that $e \cdot n \ne \bot$ for every $n \in \NN$, we have that $\NN \ni e \cdot n \Vdash_1 f(x) = *$, for every $x \in |X|$ and $n \Vdash_X x$, so $e$ is a tracker of $f$.
        \item Given two assemblies $X = (|X|,\Vdash_X)$ and $Y = (|Y|,\Vdash_Y)$, we fix an injective pairing function $\texttt{cons} : \NN^2 \hookrightarrow \NN$, defined as $\texttt{cons}(n,m) := \frac{(n+m)(n+m+1)}{2} + m + 1$,
        with inverses $\texttt{car} : \NN \to \NN$ and $\texttt{cdr} : \NN \to \NN$, such that
        \[ \texttt{car}(\texttt{cons}(n,m)) = n \quad\text{and}\quad \texttt{cdr}(\texttt{cons}(n,m)) = m\footnote{They can be explicitly defined as $\texttt{car}(z) := \sum_{i < z}\sum_{j < z} i \cdot (1 \mathbin{\dot{-}} \{z = \texttt{cons}(i,j)\})$ and $\texttt{cdr}(z) := \sum_{i < z}\sum_{j < z} j \cdot (1 \mathbin{\dot{-}} \{z = \texttt{cons}(i,j)\})$,
        where $\mathbin{\dot{-}}$ is the dot-minus operation, and $\{z = \texttt{cons}(i,j)\}$ represents the corresponding truth value of the equality inside, which can be written via a primitive recursive function, see \cite{KomaraRecursiveFunctions2011}.}.\]
        These are all primitive recursive functions, and we will denote $\texttt{cons}(n,m)$ as $\langle n,m \rangle$ for brevity. We define
        \[ \langle n,m \rangle \Vdash_{X \times Y} (x,y) \overset{\textnormal{def}}{\iff} n \Vdash_X x \;\text{and}\; m \Vdash_Y y. \]
        The projections $\pi_X : X \times Y \to X$ and $\pi_Y : X \times Y \to Y$ are defined as the underlying functions $\pi_X(x,y) := x$ and $\pi_Y(x,y) := y$, and are morphisms of assemblies, since, for example,
        \[ \langle n, m \rangle \Vdash_{X \times Y} (x,y) \implies e \cdot \langle n, m \rangle \Vdash_X \pi_{X,Y}(x,y) = x, \]
        by taking $e := \ulcorner \texttt{car} \urcorner \in \NN$, and similarly for $\pi_{X,Y}'$.
        Given $f : Z \to X$ and $g : Z \to Y$, we define the morphism $\langle f,g \rangle : Z \to X \times Y$ as the underlying function $\langle f,g \rangle(z) := (f(z),g(z))$ that already is unique and makes the diagram commute.
        In order to have that $\langle f,g \rangle$ is a morphism of assemblies, we need to find a tracker such that
        \[ n \Vdash_Z z \implies e \cdot n \Vdash_{X \times Y} (f(z),g(z)), \]
        where the last condition is equivalent to $\texttt{car}(e \cdot n) \Vdash_X f(z)$ and $\texttt{cdr}(e \cdot n) \Vdash_Y g(z)$. Since $f$ and $g$ are morphisms we can fix two trackers $e_f$ and $e_g$ such that $e_f \cdot n \Vdash_X f(z)$ and $e_g \cdot n \Vdash_Y g(z)$,
        and we can define $e := \ulcorner \langle u_1(e_f,-),u_1(e_g,-) \rangle \urcorner \in \NN$, and it is easy to check that $e$ respects the two conditions above and that $e \cdot n \ne \bot$ whenever $n \Vdash_Z z$.
        \item Given two assemblies $X = (|X|,\Vdash_X)$ and $Y = (|Y|,\Vdash_Y)$, we define the assembly $Y^X := (|Y^X|,\Vdash_{Y^X})$, where $|Y^X| \subseteq |Y|^{|X|}$ is the subset of functions $f : |X| \to |Y|$ for which there exists an $e \in \NN$ satisfying the condition below, and
        \[ e \Vdash_{Y^X} f \overset{\textnormal{def}}{\iff} \forall x \in |X| \; \forall n \in \NN \; (n \Vdash_X x \implies e \cdot n \ne \bot \text{ and } e \cdot n \Vdash_Y f(x)),\]
        i.e. $e$ realizes $f$ if it is a tracker of $f$ as a morphism of assemblies. We want to check that there is a bijection
        \[ \Hom_{\mathsf{Asm}(\mathcal K_1)}(X \times Y,Z) \overset{1:1}{\longleftrightarrow} \Hom_{\mathsf{Asm}(\mathcal K_1)}(X,Z^Y). \]
        Let's define the map
        \[ (-)^* : \Hom_{\mathsf{Asm}(\mathcal K_1)}(X \times Y,Z) \to \Hom_{\mathsf{Asm}(\mathcal K_1)}(X,Z^Y) : f \mapsto f^*, \]
        where $f^* : X \to Z^Y$ is defined as the underlying function $f^*(x)(y) := f(x,y)$, and we need to check that $f^* : X \to Z^Y$ is a morphism of assemblies.
        Given $n \Vdash_X x$ we look for a tracker $e \in \NN$ such that $e \cdot n \ne \bot$ and $e \cdot n \Vdash_{Z^Y} f^*(x)$, i.e. for every $y \in |Y|$ and $m \in \NN$, if $m \Vdash_Y y$ then $(e \cdot n) \cdot m \ne \bot$ and $(e \cdot n) \cdot m \Vdash_Z f^*(x)(y) = f(x,y)$.\newline
        By the hypothesis, $f : X \times Y \to Z$ is a morphism of assemblies, so if $\langle n,m \rangle \Vdash_{X \times Y} (x,y)$, then there exists a tracker $e_f \in \NN$ such that $e_f \cdot \langle n,m \rangle \ne \bot$ and $e_f \cdot \langle n,m \rangle \Vdash_Z f(x,y)$.
        Define the partial recursive function $k : \NN^2 \to \NN_\bot$ by $k(n,m) := e_f \cdot \langle n,m \rangle$. By the $s$-$m$-$n$ theorem \cite{WikipediaSmnTheorem2026}, $s_1^1(\ulcorner k \urcorner,n)$ is an index of the partial function $m \mapsto k(n,m)$, and the map $n \mapsto s_1^1(\ulcorner k \urcorner,n)$ is total recursive. Let
        \[ e := \ulcorner n \mapsto s_1^1(\ulcorner k \urcorner,n) \urcorner \in \NN. \]
        Then, whenever $m \Vdash_Y y$,
        \[ (e \cdot n) \cdot m = u_1(s_1^1(\ulcorner k \urcorner,n),m) = u_2(\ulcorner k \urcorner,n,m) = e_f \cdot \langle n,m \rangle \Vdash_Z f(x,y). \]
        Since $e \cdot n$ is always defined and $e_f \cdot \langle n,m \rangle \ne \bot$, $e$ is a tracker of $f^*$.\newline
        On the other hand, we define the map
        \[ (-)^\sharp : \Hom_{\mathsf{Asm}(\mathcal K_1)}(X,Z^Y) \to \Hom_{\mathsf{Asm}(\mathcal K_1)}(X \times Y,Z) : g \mapsto \ev_{Z,Y} \circ \langle g \circ \pi_{X,Y},\pi_{X,Y}' \rangle, \]
        where $\ev_{Z,Y} : Z^Y \times Y \to Z$ is the set-theoretic evaluation map $\ev_{Z,Y}(f,y) := f(y)$, and if we check that it is a morphism of assemblies, then $g^\sharp$ is a morphism of assemblies too, via composition and pairing - that we already know preserve morphisms of assemblies.\newline
        Given $\langle n,m \rangle \Vdash_{Z^Y \times Y} (f,y)$, we need to find a tracker $e \in \NN$ such that $e \cdot \langle n,m \rangle \ne \bot$ and $e \cdot \langle n,m \rangle \Vdash_Z \ev_{Z,Y}(f,y) = f(y)$.
        By the definition of $\Vdash_{Z^Y}$, $n$ is itself a tracker of $f$, so $m \Vdash_Y y$ implies $n \cdot m \ne \bot$ and $n \cdot m \Vdash_Z f(y)$.
        If we take $e := \ulcorner u_1(\texttt{car}(-),\texttt{cdr}(-)) \urcorner \in \NN$, then
        \[ e \cdot \langle n,m \rangle = n \cdot m \Vdash_Z f(y), \]
        and since $n \cdot m \ne \bot$, we have that $e$ is a tracker of $\ev_{Z,Y}$.\newline
        Finally, since $\mathsf{Asm}(\mathcal K_1)$ is a concrete category, two morphisms of assemblies with the same underlying function are equal. Thus,
        since we know that the set-theoretic maps $(f^*)^\sharp$ and $f$ are equal, then they are equal as morphisms of assemblies, and similarly for $(g^\sharp)^*$ and $g$, so the two maps $(-)^*$ and $(-)^\sharp$ are inverse to each other.
    \end{itemize}
\end{proof}

Finally we can prove Rice's theorem.

\begin{proof}
    Let's assume, by contradiction, that $R \subseteq \NN$ is a nontrivial extensional property of the partial recursive functions, i.e. there's an element $r \in R$ and an element $s \notin R$.
    Let $\mathbf N := (\NN,\Vdash_{\mathbf N})$, where $n \Vdash_{\mathbf N} m$ if and only if $n=m$, and let $P$ be the assembly of unary partial recursive functions, where
    \[ |P| := \{u_1(e,-)\mid e\in\NN\}, \qquad e\Vdash_P f \iff u_1(e,-) = f. \]
    Let $h(e,n,x):=u_1(u_1(e,n),x)$ and, using the notation of the $s$-$m$-$n$ theorem, define the total recursive functions
    \[ S(e,n) := s_1^2(\ulcorner h\urcorner,e,n), \qquad T(e) := s_1^1(\ulcorner S\urcorner,e). \]
    Then $u_1(S(e,n),x)=h(e,n,x)$ and $u_1(T(e),n)=S(e,n)$, so the map $\phi:\mathbf N\to P^{\mathbf N}$ defined by $\phi(e)(n):=u_1(S(e,n),-)$ is a morphism of assemblies, tracked by $\ulcorner T\urcorner$.
    Moreover, if $g:\mathbf N\to P$ is a morphism with tracker $a$, then
    \begin{align*}
        \phi(a)(n) &= u_1(S(a,n),-) \\
                   &= u_1(s_1^2(\ulcorner h\urcorner,a,n),-) \\
                   &= h(a,n,-) \\
                   &= u_1(a \cdot n, -) = g(n)(-)
    \end{align*}
    for every $n\in\NN$; hence, $\phi$ is point-surjective. Since $R$ is extensional, the endomorphism
    \[ F:P\to P:f\mapsto\begin{cases} u_1(s,-) & \text{if $f$ has a realizer in $R$}\\
                                      u_1(r,-) & \text{otherwise}
    \end{cases} \]
    is well-defined, and it is a morphism because it is tracked by the total recursive function that maps $e$ to $s$ if $e\in R$ and to $r$ otherwise;
    this function is total recursive since $R$ is decidable. By Lawvere's fixed-point theorem, $F$ has a fixed point, which is impossible: by construction, $F$ sends functions whose indices belong to $R$ to a function whose indices do not belong to $R$, and vice versa.
\end{proof}

\subsection*{Fixed-point for extensional operators}
\begin{definition}[Acceptable enumeration]
    An enumeration $(W_n)_{n\in\NN}$ of the recursively enumerable subsets of $\NN$ is \emph{acceptable} if there exist total recursive functions $p,q:\NN\to\NN$ such that, for every $n\in\NN$,
    \[ W_n=\mathrm{dom}(u_1(p(n),-)) \qquad\text{and}\qquad \mathrm{dom}(u_1(n,-))=W_{q(n)}, \]
    where $\mathrm{dom}(u_1(n,-)) := \{x \in \NN : u_1(n,x) \ne \bot\}$.
\end{definition}

Fix an acceptable enumeration $(W_n)_{n\in\NN}$ of the recursively enumerable subsets of $\NN$, and let $\mathrm{RE}:=\{W_n\mid n\in\NN\}$.\label{idx:re-sets}
In this setting, we can give the following definition.

\begin{definition}[Extensional operator]
    We say that a function $F : \mathrm{RE} \to \mathrm{RE}$ is an \emph{extensional operator} if there exists a total recursive function $\varphi : \NN \to \NN$ such that, for every $n \in \NN$
    \[ F(W_n) = W_{\varphi(n)} \qquad \text{and} \qquad W_n = W_m \implies W_{\varphi(n)} = W_{\varphi(m)}. \]
\end{definition}

\begin{remark}
    The second condition in the definition above is necessary, since it says that $F$ is well-defined independently of the fixed enumeration of $\mathrm{RE}$'s sets.
\end{remark}

\begin{theorem}[Fixed-point for extensional operators]
    Every extensional operator $F : \mathrm{RE} \to \mathrm{RE}$ has a fixed point, i.e. there exists $n \in \NN$ such that $F(W_n) = W_{\varphi(n)} = W_n$.
\end{theorem}

\begin{remark}[Rogers $\implies$ fixed-point of extensional operators]
    This theorem follows from Rogers' fixed-point theorem, which we will talk about in the next subsection, but it can also be proved directly from Lawvere's fixed-point theorem, as we will see in a moment.
\end{remark}

\begin{proof}
    Equip $\mathrm{RE}$ with the assembly structure $n \Vdash_{\mathrm{RE}} W$ if and only if $W_n=W$.
    Replacing each partial recursive function in the point-surjective morphism constructed in the proof of Rice's theorem by its domain gives a point-surjective morphism $\mathbf N\to\mathrm{RE}^{\mathbf N}$.
    Therefore, Lawvere's fixed-point theorem provides a fixed point for every extensional operator $F : \mathrm{RE} \to \mathrm{RE}$.
\end{proof}

\subsection*{Rogers' fixed-point theorem}
With the assemblies $\mathbf N$ and $P$ introduced above, Rogers' fixed-point theorem is not a direct instance of Lawvere's fixed-point theorem:
an arbitrary total recursive function $\varphi:\NN\to\NN$ need not preserve equality of the partial recursive functions represented by its inputs, i.e., $u_1(n,-) = u_1(m,-)$ does not imply $u_1(\varphi(n),-) = u_1(\varphi(m),-)$, and therefore need not induce an endomorphism of $P$.\newline
Nevertheless, it is still interesting to see how the diagonal construction in the proof of Lawvere's theorem can be repeated at the level of indices, using the point-surjective morphism $\phi:\mathbf N\to P^{\mathbf N}$ constructed in the proof of Rice's theorem.
More precisely, the morphism $g$ below plays the role of the term $q(x)=f(\phi(x)(x))$, while $\phi(a)(a)=u_1(S(a,a),-)$ is the corresponding self-application.

\begin{theorem}[Rogers' fixed-point theorem]
    Given a total recursive function $\varphi : \NN \to \NN$, there exists $n \in \NN$ such that
    \[ u_1(\varphi(n),-) = u_1(n,-). \]
\end{theorem}

\begin{proof}
    Define the morphism $g : \mathbf N \to P$ by
    \[ g(e) := u_1(\varphi(S(e,e)),-) \in P. \]
    Let $a$ be an index of $e \mapsto \varphi(S(e,e))$, i.e. $u_1(a,e) = \varphi(S(e,e));$ then $a$ tracks $g$, and the point-surjectivity calculation in the proof of Rice's theorem gives $\phi(a)=g$.
    Setting $n:=S(a,a)$, we obtain
    \[ u_1(n,-) = \phi(a)(a) = g(a) = u_1(\varphi(S(a,a)),-) = u_1(\varphi(n),-). \]
\end{proof}

\subsection*{Existence of $Y$-combinator for reflexive objects}\label{idx:y-combinator}
We conclude this section by showing that Lawvere's fixed-point theorem can be used to prove the existence of a $Y$-combinator for reflexive objects in cartesian closed categories.
The $Y$-combinator is a morphism $Y : U^U \to U$ that sends every endomorphism $f : U \to U$ to one of its fixed points, i.e. $Y \circ \ulcorner f \urcorner : 1 \to U$ is a fixed point of $f$.
Therefore, it can be seen as a uniform fixed-point operator, and it is the categorical counterpart of the $Y$-combinator in $\lambda$-calculus.


\begin{definition}[Reflexive object]
    Let $\mathcal C$ be a cartesian closed category; given $U$ an object of $\mathcal C$, we say that $U$ is \emph{reflexive} if there exists a pair of morphisms
    \[ r : U \to U^U \qquad\text{and}\qquad s : U^U \to U, \]
    such that $r \circ s = 1_{U^U}$, i.e. $s$ is a section of $r$, which means that $r$ is surjective.
\end{definition}

\begin{theorem}[Existence of $Y$-combinator]
    Given a reflexive object $U$ in a cartesian closed category $\mathcal C$, there exists a morphism $Y : U^U \to U$ such that
    \[ \ev_{U,U} \circ \langle 1_{U^U},Y \rangle = Y. \]
\end{theorem}

\begin{proof}
    Let $x:1\to U^U$ be an indeterminate and work in $\mathcal C[x]$. Since $r\circ s=1_{U^U}$ continues to be true also in $\mathcal C[x]$, the morphism $r$ is weakly point-surjective in $\mathcal C[x]$.
    Thus, Lawvere's fixed-point theorem applied to the endomorphism $x^\sharp:U\to U$ gives a morphism $p(x):1\to U$ such that
    \[ x^\sharp\circ p(x)\underset{x}{=}p(x). \]
    By Lambek's normal form, \Cref{cor:lambeks-normal-form}, there is a unique morphism $Y:U^U\to U$ such that $Y \circ x \underset{x}{=} p(x)$.
    Now we have that
    \begin{align*}
        (\ev_{U,U}\circ\langle 1_{U^U},Y\rangle)\circ x
        &\underset{x}{=}\ev_{U,U}\circ\langle x,Y\circ x\rangle \\
        &\underset{x}{=}\ev_{U,U}\circ\langle x,p(x)\rangle \\
        &\underset{x}{=} \ev_{U,U} \circ \langle x \circ !_U, 1_U \rangle \circ p(x) \\
        &\underset{x}{=} x^\sharp \circ p(x) \underset{x}{=} p(x).
    \end{align*}
    Therefore, by the uniqueness in \Cref{cor:lambeks-normal-form}, we must have
    \[ \ev_{U,U} \circ \langle 1_{U^U}, Y \rangle = Y. \]
\end{proof}

\begin{corollary}[Uniform fixed-point for reflexive objects]
    Let $U$ be a reflexive object and let $Y:U^U\to U$ be as above. For every endomorphism $f:U\to U$, the global element
    \[ p_f:=Y\circ\ulcorner f\urcorner:1\to U \]
    is a fixed point of $f$.
\end{corollary}

\begin{proof}
    Since $\ulcorner f\urcorner^\sharp=f = \ev_{U,U} \circ \langle \ulcorner f \urcorner \circ !_U, 1_U \rangle$, we have
    \begin{align*}
        f\circ p_f &= (\ev_{U,U} \circ \langle \ulcorner f \urcorner \circ !_U, 1_U \rangle) \circ (Y\circ\ulcorner f\urcorner) \\
                   &= \ev_{U,U} \circ \langle \ulcorner f \urcorner \circ !_U \circ Y \circ \ulcorner f\urcorner, Y \circ \ulcorner f\urcorner \rangle \\
                   &= \ev_{U,U} \circ \langle\ulcorner f \urcorner, Y \circ \ulcorner f\urcorner\rangle \\
                   &= (\ev_{U,U} \circ \langle 1_{U^U}, Y \rangle) \circ \ulcorner f\urcorner = Y \circ \ulcorner f\urcorner = p_f.
    \end{align*}
\end{proof}


\section{Lawvere's fixed-point, cartesian form}
We can also prove a generalization of Lawvere's fixed-point theorem that holds in a cartesian category, and it is equivalent to the original one in a cartesian closed category, because of the bijection given by Proposition~\ref{prop:morphisms-as-global-elements}.

\begin{definition}[Weakly product point-surjective]
    Given a category $\mathcal C$ with terminal object $1$, we say that a morphism $f: A \times A \to B$ is \emph{weakly product point-surjective} if, for every morphism $g : A \to B$,
    there exists a morphism $a_g : 1 \to A$ such that $f \circ \langle a_g,a \rangle = g \circ a$ for every $a: 1 \to A$.
\end{definition}

\begin{theorem}[Lawvere's fixed-point, product form]
    Let $\mathcal C$ be a cartesian category; if there exists a weakly product point-surjective morphism $\phi : A \times A \to B$,
    then every endomorphism $f: B \to B$ has a fixed point.
\end{theorem}

\begin{proof}
    Let $f : B \to B$ be an endomorphism.
    By the equivalence $\mathsf{CC} \simeq \lambda\text{-}\mathsf{Calc}_\times$, \Cref{thm:curry-howard-lambek-cartesian-categories}, we apply $\mathbf L : \mathsf{CC} \to \lambda\text{-}\mathsf{Calc}_\times$ to $\mathcal C$ and work in its internal language $\mathbf L(\mathcal C)$.
    By the definition of $\mathbf L$, the objects of $\mathcal C$ become types, and the terms of type $B$ with free variables among $X$ are polynomial arrows $1 \to B$ in $\mathcal C[X]$; in particular, global elements become closed terms, and composition becomes substitution.
    Let $x : 1 \to A$ and $y : 1 \to B$ be indeterminates; therefore, $x \in A$ and $y \in B$ are variables in $\mathbf L(\mathcal C)$. Let's define the term
    \[ q(x) := (f \circ y)[(\phi \circ \Delta_A \circ x)/y] \in B, \]
    with no free variables other than $x$. This term corresponds to the morphism
    \[ f \circ \phi \circ \Delta_A \circ x : 1 \to B \quad \text{in } \mathcal C[x]. \]
    Applying the weak product point-surjectivity of $\phi$ to $f \circ \phi \circ \Delta_A : A \to B$ gives a closed term $p \in A$ such that
    \[ \phi \circ \langle p,a \rangle \underset{\varnothing}{=} q(x)[a/x] \]
    for every closed term $a \in A$. Taking $a=p$, we define the closed term
    \[ s := \phi \circ \langle p,p \rangle \underset{\varnothing}{=} q(x)[p/x] \in B. \]
    Using the definition of $q(x)$ and substitution, we have
    \begin{align*}
        q(x)[p/x] &\underset{\varnothing}{=} (f \circ y)[(\phi \circ \Delta_A \circ x)/y][p/x] \\
                  &\underset{\varnothing}{=} (f \circ y)[(\phi \circ \Delta_A \circ p)/y] &&(\text{by substitution}) \\
                  &\underset{\varnothing}{=} (f \circ y)[s/y] \underset{\varnothing}{=} f \circ s
    \end{align*}
    Therefore, we have $f \circ s \underset{\varnothing}{=} (f \circ y) [s/y] \underset{\varnothing}{=} s$ in $\mathbf L(\mathcal C)$.
    We now apply $\mathbf C : \lambda\text{-}\mathsf{Calc}_\times \to \mathsf{CC}$ to $\mathbf L(\mathcal C)$. By the definition of $\mathbf C$,
    the substitution of terms corresponds to the composition of classes of arrows, as follows, for a variable $u \in 1$:
    \[ [(y \in B,f \circ y)] \circ [(u \in 1,s)] = [(u \in 1,s)] \quad\text{in } \mathbf C(\mathbf L(\mathcal C)). \]
    Finally, the equivalence of categories $\mathsf{CC} \simeq \lambda\text{-}\mathsf{Calc}_\times$ provides us the natural isomorphism $\varepsilon : \mathbf C \circ \mathbf L \overset{\cong}{\Rightarrow} 1_{\mathsf{CC}}$,
    whose component at $\mathcal C$ is the isomorphism
    \[ \varepsilon_{\mathcal C} : \mathbf C(\mathbf L(\mathcal C)) \xrightarrow{\cong} \mathcal C. \]
    By the definition of $\varepsilon_{\mathcal C}$, \Cref{thm:curry-howard-lambek-cartesian-categories}, we have
    \[ \varepsilon_{\mathcal C}([(y \in B,f \circ y)]) = f, \qquad \varepsilon_{\mathcal C}([(u \in 1,s)]) = s, \]
    since $f \circ y \underset{y}{=} f \circ y$ and $s \circ u \underset{u}{=} s \circ 1_1=s$ in the respective polynomial categories.
    Therefore, applying the functor $\varepsilon_{\mathcal C}$ to the preceding arrow equation gives $f \circ s=s$ in $\mathcal C$, so $s$ is a fixed point of $f$.
\end{proof}

\section{Gödel's incompleteness and other classical results}\label{sec:godel-incompleteness-and-other-classical-results}
Using the stronger version of Lawvere's fixed-point theorem just proved, we can show how to obtain even more classical results.
In the following we're going to continue the work started in \Cref{sec:many-fixed-points-one-proof}.

\subsection*{Halting problem}
Let's consider the category of total recursive functions, $\mathsf{Rec_{tot}}$, whose objects are $1 = \{*\} = \NN^0$, $\NN^1$, $\NN^2$, $\ldots$, and whose morphisms are total recursive functions between them.\label{idx:total-recursive-category}

\begin{remark}[$\mathsf{Rec_{tot}}$ is a cartesian category]
    One can actually check that $\mathsf{Rec_{tot}}$ is a cartesian category. The identity function is total recursive. The composition of total recursive functions is again total recursive,
    and the associativity and identity laws follow from the corresponding laws in $\mathsf{Set}$.\newline
    The terminal object is $1 = \{*\}$. The product of $\NN^n$ and $\NN^m$ is $\NN^{n+m}$, and the usual projections are total recursive functions. The fact that $1$ is terminal and that the product satisfies the universal property follows from the corresponding facts in $\mathsf{Set}$.
    Formally, we could say that $\mathsf{Rec_{tot}}$ is a \emph{concrete category}, i.e., there exists a \emph{faithful} - injective on morphisms - functor $U : \mathsf{Rec_{tot}} \to \mathsf{Set}$, that is the forgetful functor.
    Therefore, given a total recursive function $f : \NN^n \to 1$, the associated function $U(f) : \NN^n \to \{*\}$ is unique, since $1$ is terminal in $\mathsf{Set}$, so $f$ is unique. Similarly one can check the universal property of the product.
\end{remark}

\begin{definition}[$H_1$]
    We call $H_1 := \{(e,x) \in \NN^2 : u_1(e,x) \ne \bot\}$ the \emph{halting set}.
\end{definition}

\begin{theorem}[Halting problem]
    The halting set $H_1$ is undecidable.
\end{theorem}

\begin{proof}
    Let's assume, by contradiction, that $H_1$ is decidable, so the following function
    \[ f : \NN^2 \to \NN : (\alpha,x) \mapsto \begin{cases}
        u_1(\alpha,x) &\text{if $(\alpha,x) \in H_1$} \\
        0 &\text{otherwise}
    \end{cases} \]
    is total recursive - since it can be expressed in terms of the function that decides $H_1$ and elementary arithmetic operations.
    We can see that, given a total recursive function $g : \NN \to \NN$, we have
    \[ f(\ulcorner g \urcorner,-) = u_1(\ulcorner g \urcorner,-) = g(-), \]
    where $\ulcorner g \urcorner$ is an index of $g$.
    Therefore, by Lawvere's fixed-point theorem in the cartesian form, every total recursive function $\NN \to \NN$ has a fixed point,
    but this is clearly a contradiction, since $s : \NN \to \NN : n \mapsto n + 1$ has none.
\end{proof}

\subsection*{Non-uniform enumerability of total recursive functions}
Following the previous example, we can also prove that the total recursive functions are not uniformly enumerable.

\begin{definition}[Uniformly enumerable sequence of functions]
    A sequence of functions $(f_n)_{n \in \NN}$, $f_n : \NN \to \NN$, is \emph{uniformly enumerable} if there exists a total recursive function $F : \NN^2 \to \NN$ such that
    \[ F(n,-) = f_n(-) \qquad \text{for every $n \in \NN$}. \]
\end{definition}

\begin{remark}
    The set of total recursive functions $\NN \to \NN$ is countable, since the set of indices of total recursive functions is a subset of $\NN$.
\end{remark}

\begin{theorem}[Non-uniform enumerability of total recursive functions]
    There is no uniformly enumerable sequence $(f_n)_{n \in \NN}$ of total recursive functions $\NN \to \NN$
    such that every total recursive function $f : \NN \to \NN$ is equal to $f_n$ for some $n \in \NN$.
\end{theorem}

\begin{proof}
    Let's assume, by contradiction, that such a sequence $(f_n)_{n \in \NN}$ exists, so there exists a total recursive function $F : \NN^2 \to \NN$ such that $F(n,-) = f_n(-)$ for every $n \in \NN$.
    Now, we notice that $F$ is a total recursive function, and by its own definition is a weakly product point-surjective morphism; therefore, Lawvere's fixed-point theorem in the cartesian form applies,
    and just like in the previous proof, we get a contradiction taking the successor function $s : \NN \to \NN$.
\end{proof}

\subsection*{Non-uniform enumerability of decidable sets}
Equivalently, we can prove that the decidable sets are not uniformly enumerable.

\begin{definition}[Uniformly enumerable sequence of sets]
    A sequence of sets $(A_n)_{n \in \NN}$, $A_n \subseteq \NN$, is \emph{uniformly enumerable} if there exists a total recursive function $G : \NN^2 \to \NN$ such that
    \[ A_n = \{x \in \NN : G(n,x) = 0\} \qquad \text{for every $n \in \NN$}. \]
\end{definition}

\begin{remark}
    We already recalled that the set of total recursive functions is countable, and we know that the set of decidable sets is countable too.
\end{remark}

\begin{theorem}[Non-uniform enumerability of decidable sets]
    There is no uniformly enumerable sequence $(A_n)_{n \in \NN}$ of decidable sets $A_n \subseteq \NN$ such that every decidable set $A \subseteq \NN$ is equal to $A_n$ for some $n \in \NN$.
\end{theorem}

\begin{proof}
    Assume such a sequence exists, witnessed by $G:\NN^2\to\NN$, and define the total recursive function
    \[ F : \NN^2 \to \NN : (n,x) \mapsto \mathbf 1_{\{G(n,x)\ne 0\}}(n,x). \]
    Then, given a total recursive $f : \NN \to \NN$ with $\Img(f)\subseteq\{0,1\}$, let $A_f := \{x \in \NN : f(x) = 0\}$; this is a decidable set, so there exists $n_f \in \NN$ such that $A_f = \{x \in \NN : G(n_f,x) = 0\}$, and therefore $F(n_f,-)=f$.
    Now $h:\NN\to\NN:n\mapsto1\mathbin{\dot{-}}n$ is a total recursive endomorphism without fixed points, while $q:\NN\to\NN:n\mapsto h(F(n,n))$ is total recursive and $\Img(q)\subseteq\{0,1\}$. Hence $F(k,-)=q$ for some $k\in\NN$, so
    \[ F(k,k)=q(k)=h(F(k,k)), \]
    a contradiction.
\end{proof}

\subsection*{Semidecidable sets are not closed under complement}
Finally, as the last application in $\mathsf{Rec_{tot}}$ let's also prove the simple fact stated in the title of this subsection.

\begin{proposition}
    There exists a semidecidable set $A \subseteq \NN$ such that its complement $A^{\complement}$ is not semidecidable.
\end{proposition}

\begin{proof}
    Let $A:=\{\langle e,x\rangle\in\NN:u_1(e,x)\ne\bot\}$, which is semidecidable, since it is the domain of a partial recursive function, and suppose that $A^{\complement}$ is semidecidable.
    It is known that in this situation there exists a total recursive function $d:\NN\to 2$ such that $d(\langle e,x\rangle)=0$ if and only if $u_1(e,x)\ne\bot$. Thus the total recursive function
    \[ F:\NN^2\to\NN:(e,x)\mapsto\begin{cases}u_1(e,x)&\text{if $d(\langle e,x\rangle)=0$},\\0&\text{otherwise}
    \end{cases} \]
    is weakly product point-surjective: for every total recursive $g:\NN\to\NN$, if $e$ is an index of $g$, then $F(e,-)=g$. Hence, by Lawvere's fixed-point theorem in the cartesian form, the successor function has a fixed point, a contradiction.
\end{proof}

\subsection*{Existence of a non-recursively enumerable language}
Let's see an application in $\mathsf{Set}$ of Lawvere's fixed-point theorem in the cartesian form. We need to introduce some preliminary definitions.

\begin{definition}[Alphabet, word, Kleene star]
    We call an \emph{alphabet} a nonempty finite set $\Sigma$. We call a \emph{word} of \emph{length} $n$ over $\Sigma$ an element of $\Sigma^n$.
    We denote by $\varepsilon$ the empty word in $\Sigma^0$, and we define the \emph{Kleene star} of $\Sigma$ to be the set of all words over $\Sigma$
    \[ \Sigma^* := \bigcup_{n \in \NN} \Sigma^n. \]
\end{definition}

\begin{notation}
    Given $a \in \Sigma$, we denote by $a^n$ the word of length $n$ over $\Sigma$ defined as $a^n := (a,\ldots,a) \in \Sigma^n$, which is also usually written as $a^n = a \ldots a$.
\end{notation}

\begin{example}[Singleton alphabet]
    If we consider $\Sigma = \{1\}$, then
    \[ \Sigma^* = \{\varepsilon, 1, 11, 111, \ldots\} = \{1^n | n \in \NN\}. \]
    Moreover, we have a natural bijection $\iota : \NN \to \Sigma^* : n \mapsto 1^n$, so we can identify $\NN$ with $\Sigma^*$.
\end{example}

\begin{definition}[Language]
    A \emph{language} over an alphabet $\Sigma$ is a subset $L \subseteq \Sigma^*$.
\end{definition}

\begin{example}
    For $\Sigma = \{1\}$, every language has the form $L = \{1^n | n \in A\}$ for some $A \subseteq \NN$,
    and, again, we can identify $L$ with the corresponding subset $A \subseteq \NN$.
    Furthermore, we can define a map $L \mapsto \widehat L := \{n \in \NN | 1^n \in L\}$ that is a bijection between $\ps(\{1\}^*)$
    and $\ps(\NN)$, so we can identify the set of languages over $\Sigma$ with the power set of $\NN$.
\end{example}

\begin{definition}[R.e. language over a singleton alphabet]
    A language $L \subseteq \{1\}^*$ is \emph{recursively enumerable} if the set
    \[ \widehat L := \{n \in \NN | 1^n \in L\} \subseteq \NN \]
    is recursively enumerable (r.e.).
\end{definition}

\begin{theorem}[Existence of a non-recursively enumerable language]
    There exists a language $L \subseteq \{1\}^*$ that is not recursively enumerable.
\end{theorem}

\begin{proof}
    Suppose, by contradiction, that every language $L \subseteq \{1\}^*$ is recursively enumerable.
    We know that the set of r.e. functions $\NN \to \NN_\bot$ is countable, so we can enumerate the r.e. languages over $\{1\}^*$ as $(L_n)_{n \in \NN}$.
    Now, we can define the function
    \[ F : \NN \times \NN \to 2 : (n,m) \mapsto \mathbf{1}_{L_n}(1^m) = \begin{cases}
        1 &\text{if $1^m \in L_n$} \\
        0 &\text{otherwise}
    \end{cases}, \]
    that is weakly product point-surjective, since for every $g : \NN \to 2$, we consider the language $L_g := \{1^m | g(m) = 1\}$, that is r.e. by assumption,
    so there exists $n_g \in \NN$ such that $L_g = L_{n_g}$, and we have $F(n_g,-) = g(-)$. Applying Lawvere's fixed-point theorem in the cartesian form, we get
    that every endomorphism $f : 2 \to 2$ has a fixed point, but this is a contradiction.
\end{proof}

\begin{remark}
    The previous theorem follows using the bijection between $\ps(\{1\}^*)$ and $\ps(\NN)$, assuming that we already know
    that there exist non-recursively enumerable subsets of $\NN$. Still, we can flip the argument
    and use the previous theorem to prove that there exist non-recursively enumerable subsets of $\NN$.
\end{remark}


\subsection*{Undefinability of the satisfaction formula}

\begin{definition}[$L_{\textnormal{arit}}$ and free variables]
    Let $L_{\textnormal{arit}}$ be the \emph{language of arithmetic}, i.e.,\ $L_{\textnormal{arit}} := \{0,+,\cdot,s\}$, and let $\FV$ denote the set of free variables of an $L_{\textnormal{arit}}$-formula,
    following the usual conventions of first-order logic, see Notation~\ref{not:free-variables-and-closed-terms}.
\end{definition}

\begin{notation}[$\mathsf{Q}$, Gödel numbering and numerals]\label{idx:godel-coding}
    We denote by $\mathsf{Q}$ the \emph{Robinson arithmetic}, see \Cite[\S~10.3, p.~67]{Smith2013}. Furthermore, we will fix a Gödel numbering $\ulcorner - \urcorner$ of the $L_{\textnormal{arit}}$-formulas,
    and denote by $\overline{n}$ the numeral corresponding to $n \in \NN$ in $L_{\textnormal{arit}}$.~\cite[\S~5.2, p.~37, and \S~19.1, pp.~136--137]{Smith2013}
\end{notation}

\begin{definition}[Definability of the satisfaction]
    Let $T$ be an $L_{\textnormal{arit}}$-theory, with $\mathsf{Q} \subseteq T$; we say that the \emph{satisfaction relation} is \emph{definable} in $T$ if there exists an $L_{\textnormal{arit}}$-formula $\mathsf{Sat}_T(y,x)$
    such that, for every $L_{\textnormal{arit}}$-formula $\varphi$, with $\FV(\varphi) \subseteq \{x\}$, and every closed $L_{\textnormal{arit}}$-term $t$, we have
    \[ T \vdash \varphi[t/x] \leftrightarrow \mathsf{Sat}_T(\overline{\ulcorner\varphi\urcorner},t). \]
\end{definition}

Intuitively, the formula $\mathsf{Sat}_T(\overline{\ulcorner\varphi\urcorner},t)$ expresses, internally in $T$, that the formula whose code is $\ulcorner\varphi\urcorner$ is satisfied by the value represented by the closed term $t$.
So there's a way of expressing the satisfaction of formulas in $T$ in $T$ itself.\newline
We need to define the category in which we will apply Lawvere's fixed-point theorem. We use the Lindenbaum category of $T$.

\begin{definition}[$\mathsf{Lind}_T$]\label{idx:lindenbaum}
    Given an $L_{\textnormal{arit}}$-theory $T$, we denote by $\mathsf{Lind}_T$ the \emph{Lindenbaum category} of $T$, whose objects are
    \[ A^n \times 2^m \qquad \text{for $n,m \in \NN$}, \]
    where $A$ represents the sort of variables, and $2$ represents the sort of propositions; here we define $1 := A^0 \times 2^0$. The morphisms are defined as follows:
    \begin{itemize}
        \item $\mathrm{Hom}(A^n,A) := \{t \in L_{\textnormal{arit}}\textnormal{-terms} \mid \FV(t)\subseteq\{x_1,\ldots,x_n\}\}/{=_T}$;
        \item $\mathrm{Hom}(A^n,2) := \{\varphi \in L_{\textnormal{arit}}\textnormal{-formulas} \mid \FV(\varphi)\subseteq\{x_1,\ldots,x_n\}\}/{\equiv_T}$;
        \item $\mathrm{Hom}(1,A) = \{\text{closed }L_{\textnormal{arit}}\text{-terms}\}/{=_T}$;
        \item $\mathrm{Hom}(1,2) = \{\text{closed }L_{\textnormal{arit}}\text{-formulas}\}/{\equiv_T}$;
        \item $\mathrm{Hom}(2,2) := \{\varphi(p) \in L_{\textnormal{arit}}(p)\textnormal{-formulas} \mid \FV(\varphi)=\varnothing\}/{\equiv_{T(p)}}$, where $p$ is a new 0-ary relation symbol;
    \end{itemize}
    Here the equivalence relations are defined by
    \[ t =_T s \overset{\textnormal{def}}{\iff} T \vdash t = s, \qquad \varphi \equiv_T \psi \overset{\textnormal{def}}{\iff} T \vdash \varphi \leftrightarrow \psi. \]\label{idx:provable-equality}
    The composition of morphisms is defined by substitution, and the identity morphisms are defined as the equivalence classes of the variables $x_i$ and the 0-ary relation symbol $p$.
\end{definition}

\begin{remark}
    To prove the undefinability of the satisfaction formula, we will only need the Hom-sets above, but to give a complete definition of the category $\mathsf{Lind}_T$, we need to define all the other Hom-sets.
    In order to do this we introduce the notation $L_{\textnormal{arit}}(p_1,\ldots,p_m)$ for the language $L_{\textnormal{arit}} \cup \{p_1,\ldots,p_m\}$, where $p_1,\ldots,p_m$ are new 0-ary relation symbols, and we define the other Hom-sets as follows:
    \begin{itemize}[leftmargin=-1.8pt]
        \item $\mathrm{Hom}(A^n \times 2^m,A) := \{t \in L_{\textnormal{arit}}(p_1,\ldots,p_m)\textnormal{-terms} \mid \FV(t)\subseteq\{x_1,\ldots,x_n\}\}/{=_{T(p_1,\ldots,p_m)}}$;
        \item $\mathrm{Hom}(A^n \times 2^m,2) := \{\varphi \in L_{\textnormal{arit}}(p_1,\ldots,p_m)\textnormal{-formulas} \mid \FV(\varphi)\subseteq\{x_1,\ldots,x_n\}\}/{\equiv_{T(p_1,\ldots,p_m)}}$;
        \item $\mathrm{Hom}(A^n \times 2^m,A^r \times 2^s)$ consists of tuples
        \[ (t_1,\ldots,t_r,\varphi_1,\ldots,\varphi_s), \]
        where each $[t_i]\in\mathrm{Hom}(A^n\times2^m,A)$ and each $[\varphi_j]\in\mathrm{Hom}(A^n\times2^m,2)$.
    \end{itemize}
    We use the notation $T(p_1,\ldots,p_m)$ to denote $T$ regarded as a theory in the extended language $L_{\textnormal{arit}}(p_1,\ldots,p_m)$, with no additional axioms.
\end{remark}

\begin{remark}[$\mathsf{Lind}_T$ is a CC]
    In order to check that $\mathsf{Lind}_T$ is a category, one should check that: the composition is well-defined, the composition and identity laws hold,
    the universal property of the terminal object $1$, and the universal property of the product. All these properties follow from the corresponding properties of the substitution of terms and formulas in first-order logic,
    and are not hard to verify, therefore we omit the details.
\end{remark}

\begin{example}
    A couple of examples of objects and morphisms in $\mathsf{Lind}_T$ are the following:
    \begin{itemize}
        \item the variable $x_i$ determines the projection $\pi_i=[x_i]:A^n\to A$;
        \item the term $x_1+x_2$ determines the morphism $[x_1+x_2]:A^2\to A$;
        \item the formula $x_1=x_2$ determines the morphism $[x_1=x_2]:A^2\to2$;
        \item the numeral $\overline{n}$ determines a point $[\overline{n}] : 1 \to A$;
        \item a closed $L_{\textnormal{arit}}$-formula $\sigma$ determines a point $[\sigma] : 1 \to 2$.
        \item the formula $\neg p$ determines the negation morphism $[\neg p]:2\to2$;
        \item a formula in two free arithmetic variables determines a morphism $A^2\to2$; in particular, if the satisfaction relation is definable, there exists a morphism
        \[ [\mathsf{Sat}_T(y,x)] : A\times A \to 2; \]
        \item $1_A = [x] : A \to A$, $1_2 = [p] : 2 \to 2$ are the identity morphisms, and $!_A = [()] : A \to 1$, $!_2 = [()] : 2 \to 1$, where $()$ is the empty tuple, are the unique morphisms to the terminal object;
    \end{itemize}
\end{example}

\begin{theorem}[Undefinability of satisfaction]
    Let $T$ be an $L_{\textnormal{arit}}$-theory such that
    \begin{enumerate}[label=(\roman*)]
        \item $T$ is consistent;
        \item $\mathsf Q\subseteq T$.
    \end{enumerate}
    Then the satisfaction relation is not definable in $T$.
\end{theorem}

\begin{proof}
    Suppose, by contradiction, that satisfaction is definable in $T$. This means that there exists a morphism in $\mathsf{Lind}_T$
    \[ [\mathsf{Sat}_T(y,x)] : A\times A \to 2. \]
    Given $g = [\varphi(x)] : A \to 2$, i.e., an equivalence class of a formula with at most one free variable, let
    \[ a_\varphi := [\overline{\ulcorner\varphi\urcorner}] : 1 \to A, \]
    be the closed term corresponding to its Gödel number.
    Given any $a=[t]:1\to A$, where $t$ is a closed $L_{\textnormal{arit}}$-term, we have
    \[ [\mathsf{Sat}_T(y,x)]\circ\langle a_\varphi,a\rangle = [\mathsf{Sat}_T(y,x)] \circ \langle[\overline{\ulcorner \varphi \urcorner}], [t]\rangle = [\mathsf{Sat}_T(\overline{\ulcorner\varphi\urcorner},t)]. \]
    By definability of satisfaction, we have
    \[ T\vdash\varphi[t/x]\leftrightarrow\mathsf{Sat}_T(\overline{\ulcorner\varphi\urcorner},t). \]
    Therefore,
    \[ [\mathsf{Sat}_T(y,x)]\circ\langle a_\varphi,a\rangle = [\mathsf{Sat}_T(\overline{\ulcorner\varphi\urcorner},t)] = [\varphi[t/x]] = g\circ a. \]
    So, the morphism $[\mathsf{Sat}_T(y,x)] : A\times A \to 2$ is weakly product point-surjective, and we can apply Lawvere's fixed-point theorem in the cartesian form to obtain that every endomorphism
    in $\Hom(2,2)$ has a fixed point. Then, the endomorphism
    \[ [\neg p] : 2 \to 2 \]
    has a fixed point $b = [\sigma] : 1 \to 2$, i.e., $[\neg p] \circ [\sigma] = [\sigma]$, so we have
    \[ [\neg \sigma] = [\sigma] \overset{\textnormal{def of $\equiv_T$}}{\implies} T \vdash \neg \sigma \leftrightarrow \sigma, \]
    contradicting the consistency of $T$. Therefore, the satisfaction relation is not definable in $T$.
\end{proof}

\begin{remark}[Uniform satisfaction formula]
    We could prove, in the same way, a stronger version of the undefinability of satisfaction, using the definition
    \[ T\vdash\forall x\left(\varphi(x)\leftrightarrow\mathsf{Sat}_T(\overline{\ulcorner\varphi\urcorner},x)\right), \]
    that is the existence of a uniformly definable satisfaction formula, i.e., the theory understands that the formula $\mathsf{Sat}_T(y,x)$ defines the satisfaction relation for every value of $x$ at once, and not only pointwise, for every closed term $t$.\newline
    However, the pointwise formulation above is the correct formulation to obtain the next undefinability result, following Lawvere's original proof of Gödel's first incompleteness theorem.
\end{remark}

\subsection*{Tarski's undefinability theorem}
Now that we have proved the undefinability of the satisfaction relation, we can prove the undefinability of truth as a consequence, following Lawvere.

\begin{definition}[Definability of truth]
    Let $T$ be an $L_{\textnormal{arit}}$-theory, with $\mathsf{Q}\subseteq T$; we say that \emph{truth} is \emph{definable} in $T$ if there exists an $L_{\textnormal{arit}}$-formula $\mathsf{Truth}_T(y)$ such that, for every closed $L_{\textnormal{arit}}$-formula $\sigma$, we have
    \[ T\vdash \sigma\leftrightarrow\mathsf{Truth}_T(\overline{\ulcorner\sigma\urcorner}). \]
\end{definition}

Intuitively, the formula $\mathsf{Truth}_T(\overline{\ulcorner\sigma\urcorner})$ expresses, internally in $T$, that the closed formula whose code is $\ulcorner\sigma\urcorner$ is true.
So $T$ understands the truth value of every closed formula in $T$ itself.

\begin{remark}[Equivalent formulation of definability of truth]
    In the Lindenbaum category $\mathsf{Lind}_T$, the formula $\mathsf{Truth}_T(y)$ determines a morphism
    \[ [\mathsf{Truth}_T(y)]:A\to2. \]
    Given an $L_{\textnormal{arit}}$-formula $\sigma$, let
    \[ c_\sigma := [\overline{\ulcorner\sigma\urcorner}] : 1\to A \]
    be the closed term corresponding to the Gödel code of $\sigma$. By composition, we have
    \[ [\mathsf{Truth}_T(y)]\circ c_\sigma = [\mathsf{Truth}_T(\overline{\ulcorner\sigma\urcorner})]; \]
    hence, truth is definable in $T$ if and only if
    \[ [\mathsf{Truth}_T(y)]\circ c_\sigma = [\sigma] \]
    for every closed $L_{\textnormal{arit}}$-formula $\sigma$. Equivalently, truth is definable in $T$ if and only if there exists a morphism $A \to 2$ which makes the following diagram commute for every closed $L_{\textnormal{arit}}$-formula $\sigma$:

Following Lawvere, it is convenient to introduce the following relation $\Gamma$ between closed terms and closed formulas that expresses the fact that a closed term is the Gödel code of a closed formula.

\begin{definition}[Code-formula relation $\Gamma$]
    We define
    \[ \Gamma\subseteq\mathrm{Hom}(1,A)\times\mathrm{Hom}(1,2) \]
    by declaring that $d\Gamma\sigma$ if there exists a closed $L_{\textnormal{arit}}$-formula $\theta$ such that
    \[ d = [\overline{\ulcorner\theta\urcorner}] \qquad\text{and}\qquad \sigma = [\theta], \]
    that is there is a closed formula such that $d$ is the numeral corresponding to its code, and $\sigma$ is the formula itself.
\end{definition}

\begin{remark}[Characterization of definability of truth]
    By the previous remark, we have that truth is definable in $T$ if and only if there exists a morphism $[\mathsf{Truth}_T(y)]:A\to2$ such that
    \[ d\Gamma\sigma\implies[\mathsf{Truth}_T(y)]\circ d = \sigma, \]
    for all $d\in\mathrm{Hom}(1,A)$ and $\sigma\in\mathrm{Hom}(1,2)$.
    That means that if $d$ is the Gödel code of a closed formula $\theta$, then $[\mathsf{Truth}_T(y)]\circ d$ is the truth value of $\theta$.
\end{remark}

\begin{remark}[Substitution]
    Let $s:\NN^2\to\NN$ send $(\ulcorner\varphi\urcorner,n)$ to $\ulcorner\varphi[\overline{n}/x]\urcorner$. This function is primitive recursive \cite[Propositions~3.6 and~3.11, pp.~65, 67]{ZachIncompletenessComputability2026} and is represented by an $L_{\textnormal{arit}}$-formula \cite[Definition~4.1, p.~78, and Theorem~4.27, pp.~96--97]{ZachIncompletenessComputability2026}.
    The representing formula can moreover be chosen to be total in $\mathsf Q$, so that the corresponding function symbol may be added to the language, see \cite[\S~16.3, pp.~122--123, especially Theorem~16.4]{Smith2013} for the details. Following Lawvere \cite[pp.~143--144]{Lawvere1969}, we shall therefore assume that $\mathsf{Lind}_T$ is equipped with a morphism
    \[ \textrm{subst}:A\times A\to A \]
    such that, for every $L_{\textnormal{arit}}$-formula $\varphi$ with $\FV(\varphi)\subseteq\{x\}$ and every closed term $a:1\to A$,
    \[ \left(\textrm{subst}\circ\langle[\overline{\ulcorner\varphi\urcorner}],a\rangle\right)\,\Gamma\,[\varphi[a/x]]. \]
    So we're taking the Lindenbaum category of the corresponding extension of $T$, obtained by adding $\textrm{subst}$ as a function symbol defined by the representing formula; this does not change what $T$ proves in the original language \cite[\S~16.3(a), p.~122]{Smith2013}, and we keep the fixed Gödel numbering of $L_{\textnormal{arit}}$-formulas.
    Lastly, the passage from numerals to arbitrary closed terms follows from the fact that every closed $L_{\textnormal{arit}}$-term is provably equal in $\mathsf Q$ to a numeral \cite[Lemma~4.34, pp.~100--101]{ZachIncompletenessComputability2026}.
\end{remark}

\begin{theorem}[Undefinability of truth]
    Let $T$ be an $L_{\textnormal{arit}}$-theory such that
    \begin{enumerate}[label=(\roman*)]
        \item $T$ is consistent;
        \item $\mathsf Q \subseteq T$.
    \end{enumerate}
    Then truth is not definable in $T$.
\end{theorem}

\begin{proof}
    Suppose by contradiction that truth is definable in $T$, then we can consider the corresponding morphism
    \[ [\mathsf{Truth}_T(y)] : A \to 2. \]
    We define
    \[ [\mathsf{Sat}_T(y,x)] := [\mathsf{Truth}_T(y)] \circ \textrm{subst} : A \times A \to 2. \]
    Let $\varphi$ be an $L_{\textnormal{arit}}$-formula with $\FV(\varphi)\subseteq\{x\}$, and let $t$ be a closed $L_{\textnormal{arit}}$-term. By the definition of $\textrm{subst}$, we have
    \[ \left(\textrm{subst} \circ \langle[\overline{\ulcorner\varphi\urcorner}],[t]\rangle\right)\Gamma[\varphi[t/x]]. \]
    Hence, by definability of $\mathsf{Truth}_T$
    \[ [\mathsf{Truth}_T(y)] \circ\textrm{subst} \circ \langle[\overline{\ulcorner\varphi\urcorner}],[t]\rangle = [\varphi[t/x]], \]
    and therefore
    \[ [\mathsf{Sat}_T(y,x)] \circ\langle[\overline{\ulcorner\varphi\urcorner}],[t]\rangle = [\varphi[t/x]]. \]
    So, by the definition of $\equiv_T$, we have
    \[ T\vdash\varphi[t/x]\leftrightarrow\mathsf{Sat}_T(\overline{\ulcorner\varphi\urcorner},t). \]
    Therefore, the satisfaction formula is definable in $T$, contradicting the previous theorem.
\end{proof}

\begin{remark}
    We could have proved the undefinability of truth directly, without using the undefinability of satisfaction,
    repeating the same argument, based on the Lindenbaum category and Lawvere's fixed-point theorem, but this
    would have basically been a repetition of the previous proof. Therefore, we preferred to follow
    Lawvere's exposition \cite[pp.~143--144]{Lawvere1969}, and let the undefinability of truth follow from the undefinability of satisfaction.
\end{remark}

\subsection*{Gödel's first incompleteness theorem}
Now that we have proved the undefinability of truth, we can prove Gödel's first incompleteness theorem,
obtaining a proof that directly follows from Lawvere's fixed-point theorem, as Lawvere did in \cite[pp.~144--145]{Lawvere1969}.

\begin{definition}[Representability of provability]
Following Lawvere, we say that \emph{provability is representable relative to $\Gamma$} if there exists a morphism
\[ [\mathsf{Pr}_T(y)] : A \to 2 \]
such that, for every closed term $d : 1 \to A$ and closed formula $\sigma : 1 \to 2$,
\[ d\Gamma\sigma \implies \left([\mathsf{Pr}_T(y)] \circ d = [\top] \iff \sigma = [\top]\right), \]
i.e. $\sigma$ is true for $T$ if and only if the arrow $[\mathsf{Pr}_T(y)]$ identifies, one of its codes $d$, as a code for the true formula.
\end{definition}

This is weaker than the definability of truth, since it only requires that the provability formula correctly recognizes the closed formulas that are provable in $T$,
rather than reproducing the truth value of every closed formula. As a corollary of Gödel's incompleteness proof, it will follow that, assuming completeness, the two conditions are equivalent.

\begin{remark}[Representability of provability]
    Let $T$ be a recursively axiomatizable theory such that $\mathsf Q \subseteq T$. By Craig's reaxiomatization theorem, we may choose a primitive recursive axiomatization of $T$ \cite[Propositions~6.15 and~6.16, pp.~146--147]{ZachIncompletenessComputability2026}.
    Relative to this axiomatization, the binary relation $\mathsf{Prf}_T(x,y)$, which holds if $x$ is the code of a proof in $T$ of the sentence with Gödel number $y$, is primitive recursive \cite[Proposition~3.19, pp.~73--74]{ZachIncompletenessComputability2026}, and is therefore represented in $\mathsf Q$, hence in $T$, by an $L_{\textnormal{arit}}$-formula \cite[Definition~4.28 and Theorem~4.29, pp.~97--98]{ZachIncompletenessComputability2026}.\newline\label{idx:proof-predicate}
    Define $\mathsf{Pr}_T(y):=\exists x\,\mathsf{Prf}_T(x,y)$. If $T\vdash\sigma$, representability of $\mathsf{Prf}_T$ gives $T\vdash\mathsf{Pr}_T(\overline{\ulcorner\sigma\urcorner})$. Conversely, if $T\vdash\mathsf{Pr}_T(\overline{\ulcorner\sigma\urcorner})$, then the soundness assumption $\mathbb N\models T$ used below implies $\mathbb N\models\mathsf{Pr}_T(\overline{\ulcorner\sigma\urcorner})$; hence a proof in $T$ of $\sigma$ exists, so $T\vdash\sigma$. Thus $[\mathsf{Pr}_T(y)]:A\to2$ represents provability relative to $\Gamma$.
\end{remark}

\begin{theorem}[Gödel's first incompleteness theorem]
    Let $T$ be an $L_{\mathrm{arit}}$-theory such that
    \begin{enumerate}[label=(\roman*)]
        \item $T$ is recursively axiomatizable;
        \item $\mathsf Q\subseteq T$;
        \item $\mathbb N\models T$.
    \end{enumerate}
    Then $T$ is incomplete.
\end{theorem}

\begin{proof}
    Since $\mathbb N\models T$, the theory $T$ is consistent and provability is representable relative to $\Gamma$.
    Suppose, by contradiction, that $T$ is complete. Then, for every closed formula, $T$ is capable of proving it or proving its negation, and therefore
    \[ \mathrm{Hom}(1, 2) = \{[\bot], [\top]\}. \]
    Let $\sigma : 1 \to 2$ and $d : 1 \to A$ be chosen arbitrarily. We have two cases:
    \begin{itemize}
        \item if $\sigma = [\top]$, then, by definition of representability of provability, we have
        \[ d\Gamma\sigma \implies [\mathsf{Pr}_T(y)] \circ d = [\top]; \]
        \item if $\sigma = [\bot]$, then, since $T$ is consistent, $\sigma \ne [\top]$, so by definition of representability
        \[ d\Gamma\sigma \implies [\mathsf{Pr}_T(y)] \circ d \ne [\top]. \]
        Since we have only two classes of closed formulas, it follows that
        \[ [\mathsf{Pr}_T(y)] \circ d = [\bot] = \sigma. \]
    \end{itemize}
    Therefore, in both cases $d\Gamma\sigma$ implies $[\mathsf{Pr}_T(y)] \circ d = \sigma$; this $[\mathsf{Pr}_T(y)] : A \to 2$
    defines truth relative to $\Gamma$, contradicting the previous theorem.
\end{proof}

    The proof of Gödel's first incompleteness theorem can be summarized in proving that $[\mathsf{Pr}_T(y)]$ has, under Gödel's assumptions,
    the same universal property as $[\mathsf{Truth}_T(y)]$, that is, if $d\Gamma\sigma$, then $[\mathsf{Pr}_T(y)]$ makes the following diagram commute:

\subsection*{Gödel's diagonal lemma}
Just like we did for Cantor's diagonal argument, we can also prove Gödel's diagonal lemma using the
proof of Lawvere's fixed-point theorem in the cartesian form. This is another way of deriving Gödel's first incompleteness theorem from Lawvere's fixed-point theorem, following \cite[Theorem~4, pp.~376--377]{Yanofsky2003} and noticing that there's an imprecision \cite{Vestrucci2026}.

\begin{notation}[Raw formulas]
    Let $\mathsf{Form}_1$ be the set of $L_{\textnormal{arit}}$-formulas $\theta$ such that $\FV(\theta)\subseteq\{x\}$, and let $\mathsf{Form}_0\subseteq\mathsf{Form}_1$ be the set of closed $L_{\textnormal{arit}}$-formulas.
    We work below in the cartesian category $\mathsf{Set}$, regarding $\mathsf{Form}_1$ and $\mathsf{Form}_0$ as its objects, without quotienting by provable equivalence. This is necessary because Gödel numbering is defined on formulas, but does not descend to their Lindenbaum classes: provably equivalent formulas need not have the same Gödel code.
\end{notation}

\begin{theorem}[Gödel's diagonal lemma]
    Let $\varphi(x)$ be an $L_{\textnormal{arit}}$-formula with at most one free variable $x$; then there exists a closed $L_{\textnormal{arit}}$-formula $\psi$ such that
    \[ \mathsf Q \vdash \left(\psi \leftrightarrow \varphi[\overline{\ulcorner\psi\urcorner}/x]\right). \]
\end{theorem}

\begin{proof}
    Define the morphism
    \[ F : \mathsf{Form}_1\times\mathsf{Form}_1\to\mathsf{Form}_0 : (\theta,\chi)\mapsto\theta[\overline{\ulcorner\chi\urcorner}/x], \]
    that substitutes the Gödel code of $\chi$ for the free variable $x$ in $\theta$. For the given formula $\varphi(x)$, define the endomorphism
    \[ \Phi_\varphi : \mathsf{Form}_0\to\mathsf{Form}_0 : \sigma\mapsto\varphi[\overline{\ulcorner\sigma\urcorner}/x], \]
    i.e.,\ $\Phi_\varphi(-) := F(\varphi,-)|_{\mathsf{Form}_0}$.
    Following the Curry--Howard--Lambek proof of Lawvere's fixed-point theorem in the cartesian form, we have $\mathsf{Form}_1 = A$, $\mathsf{Form}_0 = B$, $F = \phi$ and $\Phi_\varphi = f$. Accordingly, the diagonal morphism corresponding to the term $q(x)$ in that proof is
    \[ g := \Phi_\varphi\circ F\circ\Delta_{\mathsf{Form}_1} : \mathsf{Form}_1\to\mathsf{Form}_0. \]
    Since both the predicate of being the code of an element of $\mathsf{Form}_1$ and substitution on Gödel codes are primitive recursive, there is a total primitive recursive function $D:\NN\to\NN$, with an arbitrary fixed value on numbers that do not encode elements of $\mathsf{Form}_1$, such that
    \[ D(\ulcorner\chi\urcorner) = \ulcorner F(\chi,\chi)\urcorner \]
    for every $\chi\in\mathsf{Form}_1$. Let $\delta_D(x,y)$, with $\FV(\delta_D)\subseteq\{x,y\}$, be a $\Sigma_1^0$ $L_{\textnormal{arit}}$-formula that strongly represents $D$ in $\mathsf Q$, so that
    \[ \mathsf Q\vdash\forall y\left(\delta_D(\overline n,y)\leftrightarrow y = \overline{D(n)}\right) \]
    for every $n\in\NN$. Let
    \[ \theta(x) := \exists y\left(\delta_D(x,y)\land\varphi[y/x]\right), \]
    then, for every $\chi\in\mathsf{Form}_1$, we have
    \begin{align*}
        F(\theta,\chi) &= \theta[\overline{\ulcorner\chi\urcorner}/x] \\
                       &= \exists y\left(\delta_D(\overline{\ulcorner\chi\urcorner},y)\land\varphi[y/x]\right) \\
                       &\overset{\mathsf Q}{\leftrightarrow} \exists y \left(y = \overline{D(\ulcorner\chi\urcorner)}\land\varphi[y/x]\right) \\
                       &\overset{\mathsf Q}{\leftrightarrow} \varphi[\overline{D(\ulcorner\chi\urcorner)}/x].
    \end{align*}
    On the other hand, by the definition of $g$
    \[ g(\chi) = \Phi_\varphi(F(\chi,\chi)) = \varphi[\overline{\ulcorner F(\chi,\chi)\urcorner}/x] = \varphi[\overline{D(\ulcorner\chi\urcorner)}/x]. \]
    Therefore, up to provable equivalence:
    \[ \mathsf Q\vdash F(\theta,\chi)\leftrightarrow g(\chi) \]
    for every $\chi\in\mathsf{Form}_1$. Thus $\theta$ plays exactly the role of $p$: the equation $\phi\circ\langle p,a\rangle = q(x)[a/x]$ in the cartesian proof is replaced by the preceding provable equivalence, with $\theta$ in place of $p$ and $\chi$ in place of $a$. Now define the closed formula corresponding to $s:=\phi\circ\langle p,p\rangle$ by
    \[ \psi := F(\theta,\theta) = \theta[\overline{\ulcorner\theta\urcorner}/x]. \]
    Taking $\chi = \theta$ in the preceding equivalence gives $\mathsf Q\vdash\psi\leftrightarrow g(\theta)$, while
    \[ g(\theta) = \Phi_\varphi(F(\theta,\theta)) = \Phi_\varphi(\psi) = \varphi[\overline{\ulcorner\psi\urcorner}/x]. \]
    Therefore
    \[ \mathsf Q\vdash\psi\leftrightarrow\varphi[\overline{\ulcorner\psi\urcorner}/x]. \]
\end{proof}

\begin{remark}
    From the diagonal lemma, we can derive Gödel's first incompleteness theorem following the classical argument.
    Proving the diagonal lemma and Tarski's undefinability theorem, we saw that two of the classical ways of proving Gödel's incompleteness
    can both be derived independently from Lawvere's fixed-point theorem.
\end{remark}

\subsection*{Undecidability of true arithmetic}

\begin{theorem}[Undecidability of true arithmetic]
    The set $\{\ulcorner \sigma \urcorner \in \NN : \NN \models \sigma\}$ is not recursively enumerable.
\end{theorem}

\begin{remark}
    The theorem follows both by Gödel's first incompleteness theorem and Tarski's undefinability theorem. In fact, $\mathrm{Th}(\NN;L_{\textnormal{arit}})$ is complete, consistent, contains $\mathsf{Q}$, and, if it were recursively enumerable, it would be recursively axiomatizable;
    therefore, $\mathrm{Th}(\NN;L_{\textnormal{arit}})$ would contradict the first incompleteness theorem. On the other hand, if $\mathrm{Th}(\NN;L_{\textnormal{arit}})$ were recursively enumerable, then it would be definable with a $\Sigma_1^0$ $L_{\textnormal{arit}}$-formula, contradicting Tarski's undefinability theorem.
\end{remark}

We prove this theorem using Lawvere's fixed-point theorem, since it is interesting by itself to see how it can be derived from the fixed-point theorem in a category that is not $\mathsf{Lind}_T$, but $\mathsf{Rec_{tot}}$.

\begin{proof}
    Let's assume, by contradiction, that the set $\{\ulcorner \sigma \urcorner \in \NN : \NN \models \sigma\}$ is recursively enumerable. Since $\mathrm{Th}(\NN;L_{\textnormal{arit}})$ is complete,
    the set is decidable. Let $\{\ulcorner \sigma \urcorner \in \NN : \NN \models \sigma\} = \{n : f(n) = 0\}$ for some total recursive function $f : \NN \to \NN$.\newline
    Let $\mathrm{sub} : \NN^3 \to \NN$ send $(e,n,m)$ to the Gödel code of the formula obtained by substituting $\overline n$ and $\overline m$ for the free variables $x$ and $y$ in the formula whose Gödel code is $e$, and let $\mathrm{ex} : \NN^2 \to \NN$ send $(e,n)$ to the code of $\exists y\,\varphi(\overline n,y)$; on invalid codes, let $\mathrm{ex}$ return the code of a false sentence. Both functions are primitive recursive.
    Define the total recursive function
    \[ F(e,n) := \begin{cases}\mu_m(f(\mathrm{sub}(e,n,m))=0)&\text{if $f(\mathrm{ex}(e,n))=0$},\\0&\text{otherwise}.\end{cases} \]
    Given any total recursive function $g : \NN \to \NN$, its graph is definable by a $\Sigma_1^0$ $L_{\textnormal{arit}}$-formula $\varphi_g(x,y)$, and therefore
    \[ F(\ulcorner\varphi_g\urcorner,n)=g(n). \]
    Hence $F : \NN^2\to\NN$ is weakly product point-surjective. Applying Lawvere's fixed-point theorem in the cartesian form, every total recursive endomorphism of $\NN$ has a fixed point, contradicting the fact that the successor function has none.
\end{proof}

\subsection*{Various classical paradoxes}
The barber, Grelling's, liar, and strong liar paradoxes all use the diagonal step in Lawvere's proof. In $\mathsf{Set}$, let $\phi : A\times A\to Y$, for $Y = 2 = \{0,1\}$ or $Y = \{T,M,F\} = 3$, encode the relevant relation:
\begin{itemize}[label=*]
    \item $\phi(a,x) = 1$ if the inhabitant $a$ shaves the inhabitant $x$ in the barber paradox;
    \item $\phi(a,x) = 1$ if the adjective $a$ describes the adjective $x$ in Grelling's paradox;
    \item $\phi(a,x) = 1$ if the sentence $a$ is true when it refers to the sentence $x$ ("$a(x)$" is true if and only if $\phi(a,x) = 1$);
    \item $\phi(a,x) = T$, $M$, or $F$ according to whether the sentence $a$ is true, meaningless, or false when it refers to the sentence $x$ in the strong liar paradox.
\end{itemize}
Let $t : Y\to Y$ have no fixed points. The diagonal map
\[ d(a) := t(\phi(a,a)) \]
cannot be represented by $\phi$: if $d = \phi(p,-)$ for some $p\in A$, then $\phi(p,p) = t(\phi(p,p))$. Thus $\phi$ cannot be weakly product point-surjective, and the alleged barber, heterological adjective, or liar sentence is precisely such a representative of $d$,
that therefore cannot exist. So the paradoxes are resolved by the fact that the auto-referential objects stated in the paradoxes cannot exist; otherwise, they would provide fixed points for the respective $t$ in the way just described.
\begin{center}
    \small
    \begin{tabular}{c|c|c|c}
        \textbf{Paradox} & $A$ & $Y$ & $t : Y\to Y$ \\
        \hline
        Barber & inhabitants & $2$ & $\neg$ \\
        Grelling & adjectives & $2$ & $\neg$ \\
        Liar & sentences & $2$ & $\neg$ \\
        Strong liar & sentences & $3=\{T,M,F\}$ & $t(T)=F,\quad t(M)=t(F)=T$
    \end{tabular}
\end{center}
\begin{itemize}[leftmargin=*,nosep]
    \item \textbf{Barber's paradox:} The barber ($= p$) shaves all and only those inhabitants who do not shave themselves. Does the barber shave himself?
    \item \textbf{Grelling's paradox:} An adjective is heterological if and only if it does not describe itself. Is the adjective ``heterological'' ($= p$) heterological?
    \item \textbf{Liar paradox:} ``This sentence ($= p$) is false.''
    \item \textbf{Strong liar paradox:} ``This sentence ($= p$) is not true.''
\end{itemize}

\begin{remark}
    The strong liar is stronger because adding a third value $M$, for ``meaningless'', does not avoid the contradiction: if the sentence is false or meaningless, its assertion that it is not true is true.
\end{remark}

\subsection*{Richard's paradox}
Suppose that the finite sentences defining real numbers in $[0,1)$ are enumerated, and write each number using its decimal expansion not eventually equal to $9$. Let $10:=\{0,\ldots,9\}$ and let
\[ \phi : \NN \times \NN \to 10 \]
send $(m,n)$ to the $n$-th digit of the number described by the $m$-th sentence.
If we consider the map $t : 10 \to 10$ defined by $t(1)=2$ and $t(i)=1$ for $i \ne 1$, which has no fixed point, then, following Lawvere's argument, we have the diagonal sequence
\[ d(n) := t(\phi(n,n)) \]
that defines a real number different from every number in the list, since it differs from the $m$-th one in its $m$-th digit - this is exactly the same argument as in the proof of Cantor's theorem.\newline
Richard's paradox is in the fact that it treats this diagonal rule as one of the finite descriptions in the list, producing the apparent paradox.\newline
The paradox is resolved by distinguishing the language from its metalanguage: the semantic property of being a finite sentence that defines a real number cannot itself be defined in the same language in a way that makes both the enumeration and the diagonal description available, so the latter need not belong to the list.

\section{Brouwer's fixed-point theorem}
Last but not least, one may wonder if Lawvere's theorem could be used to prove Brouwer's fixed-point theorem, following the idea
that Lawvere's result abstracts the general idea behind fixed-point and diagonal arguments. The answer to this question is not simple,
and it has been given by Rupert McCallum \Cite{McCallum2020}.

Since McCallum's paper is very technical, we will only give, in this section, a brief overview of the main results and ideas, and we refer the reader to the original paper for the details.
Therefore, we will not give a complete proof of Brouwer's theorem using the techniques explained in the paper. We will rather summarize the ideas, the results, and we will give some sketches of the proofs, to give the reader a general idea of
what the answer to the question is, and how it can be obtained.

McCallum proves, not in this order, essentially two things in the article:
\begin{itemize}
    \item in $\mathsf{ZFC}$, the hypothesis of Lawvere's classical fixed-point theorem does not hold, in general, in the category of topological spaces, already in the case of the unit interval $[0,1]$, i.e.,\ there's no topological space $A$ for which
    there exists a continuous surjection $A \twoheadrightarrow [0,1]^A$;
    \item slightly modifying the hypotheses of Lawvere's theorem, de facto using the same set $|A|$ with two different topologies, gives a slightly more general version of Lawvere's theorem that is always valid for
    a particular class of topological spaces that contains the closed balls; hence Brouwer's fixed-point follows as a corollary.
\end{itemize}

Let's see the first result. One would like to find a class of topological spaces that contains the closed balls in a finite-dimensional Euclidean space\footnote{By this, we precisely mean: finite-dimensional $\RR$ vector spaces, with a scalar product that makes them into a Hilbert space.},
and for which there exists a topological space $A$ that can be used to define an exponential topology on every object in the class, together with the continuous surjection required by Lawvere's theorem. If such
a class existed, then one could recover Brouwer's fixed-point theorem as a corollary of Lawvere's theorem. Unfortunately, this is not the case in general: as McCallum pointed out, it already fails for the unit interval $[0,1]$.

\begin{theorem}[{\cite[Theorem.~3.1.]{McCallum2020}}]
    It is provable in $\mathsf{ZFC}$ that there does not exist any topological space $A$ for which the exponential topology on $[0,1]^A$ is defined
    and such that there is a continuous surjection $g : A \to [0,1]^A$.
\end{theorem}

\begin{proof}[Proof sketch.]
    Assume that such $A$ and $g$ exist, and set $B:=(A,g)$. McCallum constructs a pair $B'=(A',g') \in L_\alpha(\RR)$ with the same properties relative to $L(\RR)$ for some countable limit ordinal $\alpha$, where $L_\alpha(\RR)$ is the $\alpha$-th level of Gödel's constructible universe over the reals, \cite{WikipediaConstructibleUniverse2026}.\newline
    For a suitable choice of a real $r$, McCallum ensures that every continuous $f:[0,1] \to [0,1]$ belonging to $L[B',\rho]$, where $\rho$ assigns to every countable ordinal $\beta$ that is a limit of limit ordinals an $\omega$-sequence of limit ordinals cofinal in $\beta$ and is restricted to $\alpha$, lies in $L_\alpha[r]$. He then constructs a model $S$ of second-order arithmetic, with the standard natural numbers, containing numerical codes for the elements and membership relation of $L_\alpha[r]$, and satisfying $\mathsf{RCA}_0$ and $\neg\mathsf{WKL}_0$, the Recursive Comprehension Axiom and the negation of Weak König's Lemma, respectively \cite{WikipediaReverseMathematics2026}.\newline
    Using the equivalence of Brouwer's fixed-point theorem with $\mathsf{WKL}_0$ over $\mathsf{RCA}_0$ \cite{WikipediaReverseMathematics2026}, McCallum claims that, by following the construction used to prove this equivalence, one obtains in $S$ a continuous map $f:[0,1] \to [0,1]$ with no fixed point in $L_\alpha[r]$.\newline
    If $B'$ occurs in $L_\alpha[r]$, and hence has its transitive closure fully encoded in $S$, then Lawvere's constructive proof can be carried out inside $S$: applied to $g'$ and $f$, it would produce a fixed point of $f$, contradicting McCallum's construction of $f$ as a map with no fixed points.
\end{proof}

Having established that Lawvere's classical fixed-point theorem does not hold in the category of topological spaces, McCallum proves a slightly modified version of Lawvere's theorem as follows.

\begin{definition}[Point-bijective morphism]
    Let $\mathcal C$ be a category with terminal object $1$. A morphism $h:A\to B$ is \emph{point-bijective} if the function
    \[ h_*:\Hom_{\mathcal C}(1,A)\to\Hom_{\mathcal C}(1,B) : a\mapsto h\circ a, \]
    is bijective. Equivalently, $h$ induces a bijection between the global elements of $A$ and those of $B$.
\end{definition}

\begin{remark}
    In $\mathsf{Top}$, a point-bijective morphism is a continuous map that is bijective on the underlying sets of the topological spaces.
\end{remark}

\begin{example}
    In $\mathsf{Top}$, let $\lvert A\rvert$ be a set equipped with two different topologies $\tau'$ and $\tau''$, with $\tau''\subsetneq\tau'$.
    Writing $A':=(\lvert A\rvert,\tau')$ and $A'':=(\lvert A\rvert,\tau'')$, the identity $\id_{|A|} : A' \to A''$ is continuous and bijective.
    Therefore we can always fix a point-bijective morphism $h : A' \to A''$ in $\mathsf{Top}$, if they have the same underlying set and the topology of $A'$ is finer than that of $A''$.
\end{example}

\begin{definition}[Subcategory]
    Let $\mathcal C$ be a category. A \emph{subcategory} of $\mathcal C$ is a category $\mathcal D$ such that $\ob(\mathcal D)\subseteq\ob(\mathcal C)$ and $\mor(\mathcal D)\subseteq\mor(\mathcal C)$.
    Moreover, the identities are the same and composition is compatible.
\end{definition}

\begin{definition}[Full subcategory]
    Let $\mathcal C$ be a category. A \emph{full subcategory} of $\mathcal C$ is a subcategory $\mathcal D$ such that
    \[ \Hom_{\mathcal C}(A,B) = \Hom_{\mathcal D}(A,B) \]
    for every $A,B\in\ob(\mathcal D)$.
\end{definition}

\begin{theorem}[Generalized Lawvere fixed-point theorem, {\cite[Theorem~1.1]{McCallum2020}}]
    \label{thm:mccallum-generalized-lawvere}
    Let $\mathcal C$ be a cartesian category, and let $\mathcal S$ be a class of objects of $\mathcal C$. Let $A'$ and $A''$ be objects of $\mathcal C$ and let $h:A'\to A''$ be point-bijective.
    Suppose that, for every $X\in\mathcal S$, the exponential $X^{A''}$ exists in a fixed full cartesian closed subcategory of $\mathcal C$ and there is a point-surjective morphism
    \[ g_X:A'\to X^{A''}. \]
    Assume moreover that every morphism $q:A'\to X$ which factors through
    \[ \langle g_X,h\rangle:A'\to X^{A''}\times A'', \]
    i.e., for which there exists a morphism $p:X^{A''}\times A''\to X$ such that
    \[ q=p\circ\langle g_X,h\rangle, \]
    also factors through $h$, i.e., there exists a morphism $\bar p:A''\to X$ such that
    \[ q=\bar p\circ h. \]
    Then every endomorphism of every $X\in\mathcal S$ has a fixed point.
\end{theorem}

\begin{proof}
    Fix $X\in\mathcal S$, let $t:X\to X$ be an endomorphism, and define
    \[ q:=t\circ\ev_{X,A''}\circ\langle g_X,h\rangle:A'\to X. \]
    This is essentially the same diagonal construction used in the classical proof of Lawvere's fixed-point theorem: whereas there one uses $(\phi\times 1_A)\circ\Delta_A=\langle\phi,1_A\rangle$, here one uses $(g_X\times h)\circ\Delta_{A'}=\langle g_X,h\rangle$, so the second copy of $A'$ is sent to $A''$ through $h$.\newline
    Using the factorization hypothesis on $q$, since it factors through $\langle g_X,h\rangle$ by definition, there is a morphism $\bar p : A''\to X$ such that $q=\bar p\circ h$.
    Since $g_X$ is point-surjective, there is a global element $a:1\to A'$ such that $g_X\circ a=\ulcorner\bar p\urcorner$.
    Thus, defining $x:=q\circ a:1\to X$, we have
    \begin{align*}
        t \circ x &= t \circ (q \circ a) \\
                  &= t \circ (\bar p \circ h \circ a) &&(\text{by the factorization}) \\
                  &= t \circ ((g_X \circ a)^\sharp \circ h \circ a) \\
                  &= t \circ (\ev_{X,A''} \circ \langle (g_X \circ a) \circ !_{A''}, 1_{A''} \rangle \circ h \circ a) \\
                  &= t \circ (\ev_{X,A''} \circ \langle g_X \circ a, h \circ a \rangle) \\
                  &= t \circ (\ev_{X,A''} \circ \langle g_X, h \rangle) \circ a \\
                  &= q \circ a = x,
    \end{align*}
    so $x$ is a fixed point of $t$.
\end{proof}

We now introduce the particular spaces and the class $\mathcal S$ of topological spaces that contains the closed balls of finite-dimensional Euclidean spaces, used by McCallum to apply this theorem.

\begin{notation}[The spaces $A'$ and $A''$]\label{idx:mccallum-spaces}
    Let $\omega_1$ be the first uncountable ordinal and let $2:=\{0,1\}$ have the discrete topology.
    Both $A'$ and $A''$ have underlying set $2^{\omega_1}$, the set of binary strings of length $\omega_1$.
    For every $\alpha<\omega_1$ and $s\in 2^\alpha$, set
    \[ N_s:=\{x\in 2^{\omega_1} : x|_\alpha=s\}. \]
    The sets $N_s$ form a basis for the topology of $A'$, whereas $A''$ carries the product topology on $2^{\omega_1}$.
    Hence the topology of $A'$ is finer than that of $A''$, and the identity on the underlying set defines a continuous point-bijective map
    \[ h:A'\to A''. \]
\end{notation}

\begin{definition}[Nice topological space, {\cite[Definition~1.2]{McCallum2020}}]
    \label{def:mccallum-nice-space}
    Let $\mathcal S$ be the class of all topological spaces $X$ satisfying the following conditions; its members are called \emph{nice}:
    \begin{enumerate}[label=(\roman*)]
        \item $X$ is compact, contractible, and there is a continuous surjection $A'\twoheadrightarrow X$;
        \item there is a decomposition $X=U\sqcup V$, where $U$ is open and dense and $V=X\setminus U$, together with a compatible metric $d$ satisfying the following local homogeneity conditions:
        \begin{enumerate}[label=(\alph*)]
            \item there is an $\varepsilon_U>0$ such that, for every $0<\delta<\varepsilon_U$, any two distinct open $d$-balls of radius $\delta$, centred at points of $U$ and whose closures are disjoint from $V$, are isometric;
            \item there is an $\varepsilon_V>0$ such that, for every $0<\delta<\varepsilon_V$, any two open $d$-balls of radius $\delta$ centred at points of $V$ are isometric.
        \end{enumerate}
    \end{enumerate}
\end{definition}

McCallum observes that every closed ball in a finite-dimensional Euclidean space belongs to $\mathcal S$: it is compact and contractible; one may take $U$ to be its interior and $V$ its boundary, and the metric conditions follow from Euclidean symmetries.
Moreover, every compact metric space is a continuous image of the Cantor space $2^\NN$ \cite{nLabCantorSpace2026}, while the restriction to the first $\omega$ coordinates gives the required continuous surjection $A'\twoheadrightarrow 2^\NN$.\par

Furthermore, since all the spaces in $\mathcal S$ are compact and have a compatible metric, they are Hausdorff, and therefore $\mathcal S$ is a subclass of $k\mathsf{Top}$, that we know is cartesian closed, so the exponential topology on $X^{A''}$ exists for every $X\in\mathcal S$.

In order to prove the desired result, we need to prove that for every $X\in\mathcal S$ there is a continuous surjection $g_X :A'\twoheadrightarrow X^{A''}$, and that every continuous map $q:A'\to X$ which factors through $\langle g_X,h\rangle$ also factors through $h$.
McCallum proves this in the following theorem.

\begin{theorem}[{\cite[Theorem~2.1]{McCallum2020}}]
    \label{thm:mccallum-brouwer}
    Let $A'$ and $A''$ be the spaces defined above and let $X\in\mathcal S$.
    Then there is a continuous surjection
    \[ g:A'\twoheadrightarrow X^{A''}, \]
    where $X^{A''}$ carries the exponential topology computed in $k\mathsf{Top}$, such that every continuous map $q:A'\to X$ which factors through $\langle g,h\rangle$ also factors through $h$.
    Consequently, every continuous endomorphism of $X$ has a fixed point.
    Since closed balls in finite-dimensional Euclidean spaces belong to $\mathcal S$, Brouwer's fixed-point theorem follows from \Cref{thm:mccallum-generalized-lawvere}.
\end{theorem}

\begin{proof}
    The proof is very long and technical so we will not give it here, and refer the reader to the original paper \Cite[p.~4--8]{McCallum2020}.
\end{proof}

Finally, we obtain as a corollary of the previous theorem Brouwer's fixed-point theorem.

\begin{corollary}[Brouwer's fixed-point theorem]
    Let $D$ be a nonempty closed ball in a finite-dimensional Euclidean space.
    Then every continuous map $f:D\to D$ has a fixed point, i.e., there exists $x\in D$ such that $f(x)=x$.
\end{corollary}
